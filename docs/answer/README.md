# 정답지 (도면에서 찍은 좌표)

`tools/도면-좌표찍기.html` 로 만든다. 파일명은 `<모듈>-<조각>.json`.

## 만드는 법

1. `tools/도면-좌표찍기.html` 을 연다 (서버 없이 파일로도 동작)
2. `docs/img/…` 도면을 불러온다
3. **보정점 3개 이상** — 제도 좌표를 아는 점을 클릭하고 그 좌표를 적는다
   ⚠ **삼각형을 이루게** 찍을 것. 일직선이면 거울 여부가 안 갈린다
   (앞중심선 위의 점만 찍으면 조각이 뒤집힌 채 「잔차 0」으로 통과한다)
4. 번호점을 클릭한다 · 곡선은 5~8점씩
5. 잔차가 **0.25cm 이하**인지 확인하고 저장

## 쓰는 법

`engine-verify.js` 가 읽어 전 번호점을 자동 대조한다. 그리고 엔진 출력을
도구에 붙여넣으면 도면 위에 겹쳐 Δ오차를 바로 보여 준다.

## 형식

```json
{ "image": "docs/img/원피스-뒤판-도면.png",
  "unit": "cm",
  "transform": { "scale_px_per_cm": 17.3, "rotation_deg": -90,
                 "mirrored": true, "residual_cm": 0.08 },
  "calib":  [ { "px": [130,800], "xy": [1.5,100] }, … ],
  "points": { "12": [23.0,21.0], "42": [17.14,11.5] },
  "curves": { "bArm": [[19.0,2.5],[18.2,6.1], …] } }
```
