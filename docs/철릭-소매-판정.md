# 철릭 긴소매 — 어느 변이 무엇인가 (2026-08-17 판정)

`철릭기본형` · `철릭프린세스` 가 공유하는 소매다. **변 이름이 통째로 뒤바뀌어
있었다.** 사용자가 화면을 보고 잡았다 (「소매가 거꾸로라 밑단 3이 안되네」 →
「암홀곡선이 위로 가야지」).

## 1. 엔진이 이렇게 읽고 있었다 (틀림)

| 변 | 엔진이 붙인 이름 | role | 시접 |
|---|---|---|---|
| 곧은 끝 (30.14) | **진동** — 몸판에 붙는 변 | `armhole` | 1.0 |
| 굽은 끝 (49.5, 세 도막) | 배래(위) · **수구** · 배래(아래) | `side`/`sleeveHem` | 1.5 / 2.5 |
| 비스듬한 두 변 (31.95 · 31.91) | 소매 윗선 · 소매 아랫선 | `shoulder`/`side` | 1.0 / 1.5 |

## 2. 실측이 이걸 부순다 (66호반 · 도면 호수)

```
몸판 진동   뒤 24.15 · 앞 23.74  = 47.89
곧은 끝     30.14        → 몸판보다 17.75 짧다.  붙일 수가 없다
굽은 끝     49.53        → 이세 1.64 (3.4%)      ★ 소매산이다
  · 굽은 끝 위 도막 25.02 ↔ 몸판 뒤 24.15   이세 0.87
  · 굽은 끝 아래 도막 23.95 ↔ 몸판 앞 23.74  이세 0.21   뒤가 크다 = 교과서
비스듬한 두 변  31.95 ↔ 31.91  차 0.040        ★ 서로 꿰매는 밑선(짝)
소매산 높이  14.74  (가장 넓은 자리 ~ 굽은 끝)  ★ 통상 14~16
```

**판정** — 굽은 끝 = **소매산(암홀)**, 곧은 끝 = **수구(소매 밑단)**,
비스듬한 두 변 = **소매 밑선**(서로 꿰맨다). 「배래」는 이 소매에 없다.

근거의 무게: ① 굽은 끝만이 몸판 진동과 길이가 맞는다 ② 두 밑선이 0.04 로 짝이다
③ 앞뒤 이세가 뒤>앞 로 교과서를 따른다 ④ 소매산 높이가 14.74 로 정상.
곧은 끝을 진동으로 보면 넷 다 설명이 안 된다.

정답지(GT)의 `landmark.긴소매` 도 같은 오독을 안고 있다 — `진동 30.22 · 수구 0.6`.
**좌표는 옳고 이름만 틀렸다.** 0.6 은 수구가 아니라 **소매산 꼭짓점**의 곧은 구간이다.

## 3. 덤으로 드러난 것 — 소매가 **그레이딩되지 않는다**

`K.sleeveAH = 30.22` 가 호수와 무관한 고정 상수라 소매산이 거의 안 자란다.

| 호수 | 몸판 진동 | 소매산 | 이세 |
|---|---|---|---|
| 44호 | 38.55 | 48.51 | **+9.96** |
| 55호 | 42.25 | 48.91 | +6.67 |
| 66호 | 46.00 | 49.33 | +3.33 |
| 66호반 | 47.89 | 49.53 | +1.64 |
| 77호 | 49.79 | 49.74 | −0.05 |
| 88호 | 53.61 | 50.16 | **−3.45** |

44호는 이세가 10cm(26%)라 못 붙이고, 88호는 3.45 **모자란다**. 도면 호수인
66호반만 맞다. 소매산은 몸판 진동에서 따라 나와야 한다 — 상수로 박을 값이 아니다
(memory `pattern-engine-techniques` ①).

## 4. 고친 것 (2026-08-17 · 1~4 순서대로)

1. **+90° 강체 회전** — 소매산이 위 · 수구가 아래. (x,y) → (폭−y, x), det=+1.
2. **변 이름·role** 을 위 표대로. 수구 = `sleeveHem` · 소매산 세 도막 = `armhole` ·
   밑선 두 개 = `side`. 그래야 시접이 제 자리에 붙고, 암홀 맞춤 너치(앞1·뒤2)가
   소매산에 붙는다 (실제로 붙었다 — 앞 1 · 뒤 2).
3. **소매폭을 몸판 진동에서 푼다.** `K.sleeveAH = 30.22` 상수를 버리고,
   「소매산 호길이 = 몸판 진동 × (1 + `capEase`)」 를 만족하는 폭을 이분법으로 찾는다.
   `capEase = 0.03501` 은 **66호반에서 도면 폭 37.112 · 수구 30.22 가 그대로
   나오는 값**이다. 수구는 `cuffRatio 0.8144`(= 30.22/37.11)로 폭을 따라간다.
4. 정답지 `landmark.긴소매` 이름을 고치고(`수구폭`·`소매산꼭지`·`소매산높이`),
   engine-verify 에 **소매산 이세** 검사를 넣었다 — §1 은 도면값 1.68 ±0.12,
   §2 는 전 호수에서 `0 < 이세 < 진동의 10%`. 밑선 짝 검사도 같이 넣었다.

폭을 37.112 로 고정하면 44호 이세 9.99 로 §2 가 잡고, 역회전을 예전 식으로 두면
외곽선 편차 8.78 로 §1 이 잡는다.
