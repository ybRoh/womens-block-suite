# 원피스 제도법 — 번호점 방식 (출처: 백영례)

**원피스 엔진(`원피스/`)의 기준 문서.** 번호점 1~78(몸판) · 1~26(소매)을 순서대로 찍어
가는 방식이고, **뒤판을 먼저 그린 뒤 복사해서 앞판을 그린다.**

원문은 55 Size 로 설명한다. 이 문서는 원문 단계를 **[n]** 으로 그대로 보존하고,
각 단계 옆에 **계산식**과 **엔진 구현 메모**를 붙였다.

> 같은 저자의 「테일러 자켓 패턴」과 같은 계열이다 —
> [테일러드재킷 제도법](테일러드재킷-제도법-백영례.md) 의 골격·용어가 그대로 통한다.

## ⚠ 원문 도면은 **90° 눕혀** 그려져 있다

이게 첫 번째 함정이다. 원문 그림에서

- **가로축(오른쪽 → 왼쪽)** = 몸의 **세로**(목 → 밑단). 오른쪽 끝이 뒤목중심(2번).
- **세로축(아래 → 위)** = 몸의 **가로**(중심선 → 옆선).
- 「2번에서 **내려온** 점 5번」은 그림에서 **왼쪽으로** 간 점이다.

엔진은 스위트 표준 좌표계를 쓴다:

```
x = 폭 (중심선 0 → 옆선 +)
y = 길이 (목 0 → 밑단 +)
```

원문 「내려온다」 → 엔진 **y 증가**, 원문 「나간다」 → 엔진 **x 증가**.
번호점을 옮길 때 이 대응을 매번 확인할 것. 도면을 눈으로 따라 읽으면 축이 뒤집힌다.

### 못 읽은 것 · 본문에 없는 것 (전수 대조 · 2026-08-13)

번호점을 전수로 훑어 **본문이 정의하지 않고 쓰기만 하는 번호**를 뽑았다.

**규칙이 모호한 곳 — 엔진에서 결정해야 한다**

- ~~**38 · 39**~~ **해결** (노이즈 제거본 · 2026-08-13) — **다트 다리의 직선 연장**이다.

  ```
  38 = 33→36 직선을 밑단까지 연장
  39 = 32→36 직선을 밑단까지 연장
  ```

  도면에서 초록선(33 쪽)이 밑단 **38**(안쪽)에, 빨간선(32 쪽)이 **39**(바깥)에 닿는다 —
  두 다리가 36번을 지나며 **자리를 바꾼다**. 즉 다트가 36번(H선 위 5) 아래에서
  다시 벌어져 밑단까지 가는 **다이아몬드 다트**이고, 이게 치마폭을 만든다.

  ★ 36번이 34번 바로 아래에 있으므로 **38·39 의 2등분은 대수적으로 35번과 정확히 같다.**
  원문의 「38~35 치수를 재서 35번에서 그만큼 밖으로 = 39」는 새 규칙이 아니라
  **이 구조가 맞는지 확인하는 검산**이다. 엔진은 직선 연장 한 번으로 끝난다.
- **44** : 「직각이 만나는 점」 — 밑단이 옆선과 90° 로 만나도록 하는 보정점.
  도면에서 40번 바로 옆(살짝 위)에 ⌐ 기호로 찍혀 있다.

**표시일 뿐 작도점이 아닌 것** — `A`(다트분 참고 치수) · `★`(유차 같은치수) ·
`■`(소매 이세 확인선) · `직각` · `1`(암홀↔등품선 간격) · `2`(어깨 내림) · `∥`(45·46)

### ★ 앞판은 뒤판과 **1:1 로 대응한다** (앞판 도면 확인 · 2026-08-13)

번호만 다르지 구조가 같다. 뒤판을 짜 두면 앞판은 같은 코드를 재사용할 수 있다.

| 뒤판 | 앞판 | 뜻 |
|---|---|---|
| 36 | **67** | 다트 끝 — H선에서 **5** 올라간 곳 |
| 35 | **66** | 다트 중심선이 밑단에 닿는 점 |
| 38 · 39 | **73 · 74** | 다트 다리를 밑단까지 연장 |
| 40 | **65** | 옆선 밑단 — 다트 벌어진 만큼 밖으로 |
| 30 | **58** | 어깨선 위 절개 출발점 |
| 32 · 33 | **68 · 69** | W선 다트점 |
| 44 | **44** | 밑단 직각 보정 (같은 번호를 쓴다) |

⚠ **[37] 의 「66번을 표시합니다」는 오기다.** 그 문장은 이미 66 을 쓰고 나서
「H라인에 생성된 선에서 5cm 올라간 곳에 점을 찍고 66번을 표시」라고 도로 66 을 말하는데,
도면에는 그 자리에 **67** 이 찍혀 있고 뒤판 36번과 같은 `→5` 표시가 붙어 있다.
→ **67 로 읽는다.**

### ★ 도면을 세우고 나서 드러난 것 3가지

**1. 「어깨를 수정합니다」[13] 는 말이 아니라 계산 단계다.**
21번을 어깨/2(19) 자리에 찍고 2 내려와 22번을 잡으면, 2~22 를 재었을 때
`√(19² + 2²) = 19.105` 로 **어깨/2 를 넘는다**. 원문이 「재서 확인하고 수정하라」는 게
이것이다. 엔진은 처음부터 맞춰야 한다:

```
x₂₂ = √( (어깨/2)² − 2² ) = √(361 − 4) = 18.894
```

**2. 어깨/2 는 어깨 솔기 길이가 아니다.**
`어깨/2` 는 **2번(뒤목중심) ~ 22번(어깨점)의 직선**이다. 실제 어깨 솔기는

| | 55 Size |
|---|---|
| 2~22 (어깨너비/2) | 19.00 |
| **20~22 (어깨 솔기)** | **12.72** |
| 20~23 (다트 포함) | 14.22 |

[33] 의 「뒤 다트분을 뺀 2분의어깨길이를 맞추어」는 **앞 어깨 솔기 = 12.72** 라는 뜻이다.
19 로 읽으면 어깨가 6 이상 길어진다.

**3. 12번 — 괄호값이 오타다.** (고해상도 확인 · 해결)
[7] 은 「**4분의유B 더하기 1.5** 나간곳(**22.5cm**)」인데 유B/4 = 21.5 이므로 식대로면 **23.0** 이다.
고해상도 도면의 12번 라벨도 **`유B/4 + 1.5`** 라 **식이 둘, 괄호값이 하나**다.
→ **23.0** 을 쓴다 (완성 가슴둘레 92 · 여유 6).

**⚠ 새로 잡힌 불일치 — 16→17 (H선 여유)**
[9] 본문은 「여유분 **1.5**cm 더 나간곳에 17번」인데, **도면에는 `↑1` 로 적혀 있다.**
W선은 도면·본문 모두 `↑1.5(여유)` 로 일치하는데 H선만 다르다.

| | 본문 | 도면 |
|---|---|---|
| W 여유 (13→14) | 1.5 | **1.5** ✓ |
| H 여유 (16→17) | 1.5 | **1** ✗ |

H 여유가 1 이면 완성 엉덩이둘레 = 90 + 4 = **94**, 1.5 면 **96** 이다.
도면 쪽(1)이 W 여유(1.5)보다 작은 것도 자연스럽다 — 엉덩이는 덜 조인다.
**K 로 빼 두고 기본은 도면값 1.0** 으로 간다.

**4. 24번 = 뒤중심선이 진동선과 만나는 점** (2026-08-13 사용자 확인 · 해결)
처음엔 24번을 못 읽어 등품선 높이를 「진동깊이의 1/2」로 가정했는데, **틀렸다**.
24번은 [6] 에서 그린 **등솔선(8→9 곡선)이 진동선을 자르는 점**이다. 그러면

```
24 = (뒤중심곡선(y=BL), BL)          55 Size → (0.31, 21)
25 = 5~24 의 2등분                    → (0.15, 21)
26 = 25 + 등품/2                      → (17.15, 21)
```

**즉 25·26·28·29 는 모두 진동선(y=21) 위에 있고, 등품선은 「세로선」이다** —
26 에서 27(y=0)까지 올라간다. 도면에서 이 점들이 진동 세로선 위에 나란히 찍힌 것도
세워 놓고 보면 「진동선 위에 x 만 다른 점들」이라 앞뒤가 맞는다.

⚠ **등품/2 는 뒤중심(x=0)이 아니라 25번에서 잰다.** 그래서 등품선이 x = 17 이 아니라
**17.15** 다. 0.15 는 등솔선이 진동선에서 이미 나가 있는 양의 절반이다.
작지만 등품·암홀·절개 통과점(29)이 전부 여기에 매달려 있으므로 식으로 두어야 한다.

## Ⅳ. 소매 — 한 장 소매로 두 장 느낌 (점 1~26)

### ⚠ 소매 도면은 **몸판과 축이 또 다르다**

몸판은 「가로 = 몸의 세로」였는데, 소매는

- **가로 = 소매길이** (오른쪽 = 소매산 정점 · 왼쪽 = 소맷부리)
- **세로 = 소매 폭** (위 = **뒤** · 아래 = **앞** — 도면에 「뒤」「앞」이 적혀 있다)

엔진 좌표 → `y = 0` 이 소매산 정점(6번) · `y = AH/3` 이 진동선(5·7번) · `y = 소매길이` 가 부리.

### ★ 소매 도면에서 확정된 것 (2026-08-13)

**1. 24번 — 「밖으로」가 아니라 안쪽이다.**
[11] 은 「3번에서 **밖으로** 나가서 24번」이라 적었지만, 도면에는 3~24 와 23~8 에
**★★ 같은치수 표시**가 붙어 있고 24 는 3 보다 **안쪽**(22 쪽)에 있다. 그래야 부리가 보존된다:

```
23 = 22 + (22~8)/2   (8 쪽으로)
24 = 3  + (22~8)/2   (22 쪽으로)
→ 실제 부리선 24~23 = 3~22 = 소매부리 (정확히 같다)
```

**부리선을 기울이되 길이는 그대로 두는** 장치다. 「밖으로」로 읽으면 부리가
`소매부리 + (22~8)` 로 늘어난다 (55 Size 예: 24 → 30.4).

**2. ■ 표시 = 봉제 짝 검사다.**
`■` 가 앞뒤 솔기에 하나씩 찍혀 있고 도면 주석이 **「앞쪽 ■ +0.5(이세분)」** 이다.

```
■ 는 앞뒤 솔기에 하나씩 찍는 **맞춤 너치**다.
앞쪽 ■ 를 뒤쪽보다 **0.5 더 나가서** 찍는다 → 봉제 때 그 0.5 만큼 앞을 홈줄인다.
```

⚠ **2026-08-14 정정.** 처음엔 이것을 「뒤 솔기 = 앞 솔기 + 0.5」라는 **길이 조건**으로
옮겨 적었다. 틀렸다. [10][11] 로 22·23·24 를 잡으면 두 솔기의 가로 span 이
**둘 다 `Lrest/2`** (`Lrest = 소매통 − 소매부리` · `23 = 22 + Lrest/2` · `24 = 3 + Lrest/2`)
라서 **두 길이는 수학적으로 반드시 같다**. 0.5 차를 만들려면 뒤 솔기를 **2.9 나
부풀려야** 하는데 그러면 도면(거의 곧은 선)과 완전히 달라진다.
도면 캡션은 「앞쪽 ■ +0.5(이세분)」 — **너치 위치** 규칙이다.

**3. 14번 = EL선 ∩ 앞 밑변.** MP 분량선(25→14)의 아래 끝이다.

### 암홀 — 「붙게」가 접선이었다 (2026-08-13)

[45] 은 「앞품 78번점과 암홀선이 **0.3~0.5 떨어지거나 붙게**」라고 한다.
처음엔 「통과점에서 0.4 밖」으로 읽고 3점 스플라인(어깨 → 통과점 → 겨드랑)으로 그렸다.
그랬더니 **어깨 끝에서 직선으로 떨어졌다가 급히 꺾여** 각져 보였다.

「붙게」는 **암홀이 품선에 접한다**는 뜻이다. 토르소프린세스가 같은 작도를 쓰고 있었다:

```
접점 A = (품선 x + 띄움, 품선 위끝 ~ 진동선의 2등분)   ← 여기서 품선에 **세로로 접한다**
오목점 H = (품선 × 진동선 모서리) 에서 [A → 겨드랑] 현에 내린 수선의 **중점**
암홀 = 스플라인(어깨, A) + 스플라인(A, H, 겨드랑)      ← A 에서 양쪽 접선이 세로
```

| 55호 | 3점 스플라인 | **2도막 접선** |
|---|---|---|
| 앞 암홀 | 17.96 | **19.36** |
| 뒤 암홀 | 19.98 | **21.36** |
| 소매산 이세 | 1.50 | **1.83** (원문 1.5~2) |

암홀이 길어지면서 이세도 원문 범위 한가운데로 들어왔다 — 3점 스플라인은 암홀을
질러가느라 짧았던 것이다.

⚠ 뒤는 [27] 이 **1** 띄우라고 하고, 앞은 [45] 가 **0.3~0.5** 다. 띄움 양만 다르고

### 소맷부리에 **호수 등급이 없었다** (2026-08-14)

「두 장 소매도 도면과 대조해줘」로 잡혔다. 원피스 원문에는 **두 장 소매 도면이 없어**
대조 대상은 ① 잘라낸 원본 한 장 소매 ② 정답지 모듈(숙녀복기본원형2)의 비율이다.
①은 정확히 맞았는데(소매산 합·부리 합·짝 전부 0.000) **부리 몫이 호수 따라 널뛰었다**:

```
큰소매 부리   44호 15.34  →  88호 14.32   ← 호수가 커지는데 **줄어든다**
```

원인은 `K.cuffW = 24` 가 **고정**이었던 것. 소매통·소매길이는 등급이 있는데 부리만 없어
44호와 88호가 같은 24 였다. 원문은 55 Size 값 24 만 주지만 자켓 표
(55~66 = 26 · 77~88 = 27 · 99 = 28)가 **대략 호당 0.5** 다.

→ `cuffGrade 0.5` 를 넣었다. 부리 23.5 / 24 / 24.5 / 25 / 25.5,
   두 장 몫도 0.632 → 0.620 으로 안정되고 **큰·작은 둘 다 호수 따라 커진다.**
   검산기에 「부리가 호수 따라 커지는가」를 넣었다.

### ★★★ 소매 좌표가 **거울상**이었다 (사용자 지적 2026-08-14)

「이미지를 90도 회전하고 너의 제도를 보면 동일하지 않고 **미러**라니까」.
도면을 90° **반시계**로 돌리면 뒤가 왼쪽·앞이 오른쪽인데, 원피스만 반대였다.

```

**길이·거리 검사는 거울에 불변**이라 89항목 중 어느 것도 못 잡았다.
좌표 규약을 `앞 +x · 뒤 −x` 로 뒤집고, 규약 검사 2개를 넣었다.

### ★★ 정수리는 **9~6 (1.5) 짜리 평평한 구간**이다

두 곡선을 9번 한 점에 모으면 앞이 급경사(42°)라 정점에서 급히 꺾여 최대곡률이
정점에 몰린다(**반지름 1.8cm** — 어깨에 못 얹는다). 장력을 올려 펴려 하면
이세가 2.5~3.6 으로 폭발한다. **평평한 1.5 가 답이다** — 이세 1.55~1.97 유지.

### ★★ 소매산의 정점은 **9번**이다 — 6번이 아니다 (사용자 지적 2026-08-14)

원문 [5] 「6번에서 **1.5 앞쪽**으로 들어온 곳 = 9번 → 10번과 직선 = **소매중심선**」.
9번을 「중심선 긋는 용도」로만 읽고 **곡선의 마루는 6번에 두고** 있었다. 틀렸다.
6번은 두 대각선(5→6 = 앞AH · 6→7 = 뒤AH)이 만나 **소매폭을 정하는** 점이고,
곡선이 넘어가는 마루는 소매중심선 위 — 즉 **9번**이다.

| 정점 | 앞 반폭 | 뒤 반폭 | 앞 기울기 | 뒤 기울기 |
|---|---|---|---|---|
| 6번 (틀림) | 15.16 | 18.34 | 39.4° | 34.1° |
| **9번 (맞음)** | **13.66** | **19.84** | **42.3°** | **32.1°** |

도면은 「**18·17 을 지나는 앞 곡선이 급경사, 7·21 을 지나는 뒤 곡선이 완만**」이다.
6번에 두면 차이가 5° 밖에 안 나 앞뒤가 뒤집혀 보인다. 9번으로 옮기면 10° 이상 벌어져
도면과 맞는다. **이세도 1.53~1.95 로 원문 [9] 안에 그대로 있다.**

⚠ 정점을 옮기면 **앞 정점 쪽 장력을 올려야** 한다 — 앞이 급경사가 되면서 정점에서
수평으로 급히 꺾여 최대곡률이 정점에 0.63(반지름 1.6cm)으로 몰렸다. `capFront.k1`
0.509 → **0.75** 로 풀면 0.55 로 내려간다. 뒤는 0.85 배로 낮춰 이세를 범위 안에 유지.

⚠ 17·21 은 이제 **현(5→9 · 7→9) 위에 있지 않다** — 21 은 7→**6** 대각선 위의 점이다.
그래서 「0 교차가 통과점 자리」 검사는 뺐다. 통과 여부는 거리 0.000 으로 따로 본다.

### 부풀림 크기 — 도면이 **자기 주석과 모순**한다 (사용자 결정 2026-08-14)

소매산 부분 고해상도를 받아 정밀 실측했다. 보정 기준은 `AH/3 = 685px → 49.2 px/cm`
(도면의 소매산/소매통 비 0.463 은 55호 계산값 0.448 과 3% 안에서 맞다 — **도면은 축척이다**).

| | 도면 실측 | 엔진 |
|---|---|---|
| 뒤 곡선 최대 편차 | **0.33** (21번 앞쪽 · 대각선~7-20 띠의 절반) | 1.08 |
| 앞 곡선 최대 편차 | **0.45** | −1.48 |
| → 곡선이 대각선보다 긴 양 = **이세** | **약 0.15** | **1.65** |

그런데 대각선은 정의상 앞AH·뒤AH 그 자체다(원문 [3][4]). 따라서
**도면에 그려진 곡선대로면 이세가 0.15 이고, 이는 같은 도면에 적힌 원문 [9]
「앞·뒤 암홀 + 이세 1.5~2」와 정면으로 어긋난다.**

→ **원문 [9] 를 따른다** (사용자 결정). 도면의 곡선은 설명용으로 얇고 좁게 그린
**모식도**로 본다. 이세 1.5~2 는 숫자로 못 박힌 검산 조건이고, 이세가 거의 없으면
소매를 달 때 실제로 문제가 된다.

**그래서 도면에서 잠그는 것은 「모양」이지 「크기」가 아니다** — 부호 프로파일
(앞 오목→볼록 · 뒤 볼록→오목), 0 교차가 통과점(17·21) 자리인가, 정점 꺾임 6° 이내.
크기는 **원문 [9] 의 이세**가 정한다.

### 몸판 암홀은 정상 — 안 맞는 것은 필요치수의 「소매통」 (2026-08-14)

「소매산 = AH/3 인데 소매통이 33~34 가 안 나온다」를 추적했다. **몸판이 아니었다.**

| 모듈 | B | AH | AH/B |
|---|---|---|---|
| 숙녀복기본원형2 | 81.6 | 40.94 | 0.502 |
| 토르소원형암홀라인 | 81.6 | 42.57 | 0.522 |
| 기본원형 | 81.6 | 43.56 | 0.534 |
| **원피스** | 84 | **41.76** | **0.497** |

원피스가 가장 낮지만 **원문 필요치수가 그렇게 준 것**이다 — 등품 34(0.405)·앞품 32(0.381)로
다른 모듈(0.436·0.406)보다 작다. 원피스는 몸에 붙는 원형이 아니라 드레스라 그럴 만하다.
번호점 좌표는 45개 전부 식과 일치하므로 **작도에는 문제가 없다.**

정리하면 원문 안에서 이 셋이 동시에 성립하지 않는다:

```
필요치수  B 84 · 어깨 38 · 등품 34 · 앞품 32   →  작도하면 AH = 41.76
원문 [2]  소매산 = AH/3 = 13.92              →  그때 소매통 31.04
필요치수  소매통 33~34
```

원문은 「소매통이 좁으면 소매산을 **0.5~1** 내린다」고 스스로 길을 열어 두었다.
실제로 필요한 하향은 **1.49** — 그 폭을 조금 넘는다. 엔진은 이 방식(소매통에서 소매산
역산)을 쓰고, 검산기가 하향폭이 1.05 를 넘으면 **경고로 계속 띄운다.**

이세 때와 같은 구조다 — **도면·필요치수·본문 중 하나는 이 판형에서 어긋난다.**
숫자로 못 박힌 검산 조건(소매통·이세)을 지키고, 어긋남은 지우지 말고 남긴다.

## Ⅸ. 프린세스 절개 4조각 (2026-08-13)

원문은 몸판을 **통짜 2조각**으로 낸다 — 어깨~밑단의 다이아몬드 다트가 안쪽 선으로만
그려져 있다. 필요치수의 「프린세스라인 : 어깨에서 절개선이 들어감」을 실제로 잘라
**뒤판(중심)·뒤옆판·앞판(중심)·앞옆판** 4조각으로 내는 옵션을 넣었다(`opt.splitPanels`).
기본값은 **0(원문 그대로 2조각)** 이다.

### 1. 조각 경계는 원문이 선을 그은 짝이 아니다

원문 [21][23][24] 는 곡자를 대는 순서대로 짝을 짓는다 — **30↔32 · 31↔33** 이고,
[24] 의 「36번에서 직선으로 내려」는 다트 다리를 **다트 끝 너머로 연장**한다.
그래서 다리가 **다트 끝(36·67번)에서 서로 교차한다**: 허리에서 안쪽이던 다리가
밑단에서는 바깥으로 간다.

조각으로 자를 때는 그 짝을 그대로 쓰면 안 된다. **끝까지 안쪽에 남는 쪽**이 중심판이다.

| | 어깨 | 허리 | 밑단 |
|---|---|---|---|
| 뒤판(중심) | 31 (12.25) | 32 (10.00) | **38** (7.27) |
| 뒤옆판 | 30 (13.65) | 33 (12.25) | **39** (14.98) |

앞을 74번(바깥)으로 잡았더니 앞 중심판과 앞옆판의 밑단이 **5.9~13.6 구간에서 겹쳤다**.

### 2. 다트 다리는 y=원피스길이가 아니라 **밑단 곡선**까지 늘린다

38·39·73·74 는 `y = 원피스길이` 자리에서 잡은 점인데 밑단은 직선이 아니다.
앞은 앞처짐 때문에 앞중심이 **1.4 내려간다**. 그대로 조각 경계로 쓰면 절개선 끝과
밑단이 1.4 어긋나 조각이 안 닫힌다(스위트 검사에서 「점 간격 1.719」로 잡혔다).
→ `toHem()` 으로 다리를 진짜 밑단선까지 늘려 38h·39h·73h·74h 를 쓴다.
밑단도 직선으로 잇지 않고 `cutAtX()` 로 **통짜 밑단 곡선의 해당 구간을 잘라** 물려준다.

### 3. 절개선 두 변의 길이 차 = 이세 (걸어 맞추지 않는다)

| 호수 | 뒤 이세 | 앞 이세 |
|---|---|---|
| 44호 | 0.233 | 0.331 |
| 55호 | 0.273 | 0.327 |
| 66호 | 0.315 | 0.323 |
| 77호 | 0.390 | 0.319 |
| 88호 | 0.433 | 0.315 |

차이는 **전부 어깨~29(70)번 구간에 있다** — 29번 아래는 32·33 이 35번 기준으로
대칭이라 저절로 같다(허리 아래 다트 다리 차 0.000). 즉 오차가 아니라 **견갑골·가슴 이세**다.

처음에는 밑단 끝점을 밀어 길이를 맞췄다(walk & true). **틀린 처방이었다** —
21cm 짜리 구간의 0.3 을 100cm 짜리 변에서 갚느라 **밑단이 2.5cm 나 밀려 나갔고**,
원문 [24]의 「38·39 의 2등분 = 35번」도 깨졌다. 길이를 맞출 자리는 차이가 생긴 자리다.

### 4. 옆선 길이 맞추기 (앞이 0.25 길다)

허리에서 **앞은 2.25 를 죄고 뒤는 0.75 만 죈다**(원문 [8][36] — 앞뒤 허리 몫은
20.75 로 같지만 가슴 폭이 앞이 1.5 넓다). 시작·끝 높이는 같은데 앞이 더 지그재그로
가므로 **앞 옆선이 0.25 길다**.

위아래 끝점은 원문이 정한 자리라 못 건드린다 → **65번을 0.25 올려** 맞춘다.
밑단은 마지막에 수평을 잡는 자유변이고, 65번의 x(18번 + 다트 벌림)는 그대로다.
전 호수에서 앞뒤 옆선 차 **0.0000**.

### 5. 절개해도 옷이 달라지면 안 된다 (제일 센 검사)

통짜 밑단에서 다트로 접히는 만큼(38h~39h · 73h~74h)을 뺀 값 = 4조각 밑단의 합.
전 호수 차 **0.04 이하**(다트 자리를 현으로 재는 데서 오는 차이 — 밑단은 곡선이다).
이게 어긋나면 절개가 치수를 먹은 것이다. `engine-verify.js` §3 에 넣었다.
