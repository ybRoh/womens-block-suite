# 원피스 제도법 — 번호점 방식 (출처: 백영례)

**원피스 엔진(`원피스/`)의 기준 문서.** 번호점 1~78(몸판) · 1~26(소매)을 순서대로 찍어
가는 방식이고, **뒤판을 먼저 그린 뒤 복사해서 앞판을 그린다.**

원문은 55 Size 로 설명한다. 이 문서는 원문 단계를 **[n]** 으로 그대로 보존하고,
각 단계 옆에 **계산식**과 **엔진 구현 메모**를 붙였다.

> 같은 저자의 「테일러 자켓 패턴」과 같은 계열이다 —
> [테일러드재킷 제도법](테일러드재킷-제도법-백영례.md) 의 골격·용어가 그대로 통한다.

## ⚠ 원문 도면은 **90° 눕혀** 그려져 있다

이게 첫 번째 함정이다. 원문 그림에서

- **가로축(오른쪽 → 왼쪽)** = 몸의 **세로**(목 → 밑단). 오른쪽 끝이 뒤목중심(2번).
- **세로축(아래 → 위)** = 몸의 **가로**(중심선 → 옆선).
- 「2번에서 **내려온** 점 5번」은 그림에서 **왼쪽으로** 간 점이다.

엔진은 스위트 표준 좌표계를 쓴다:

```
x = 폭 (중심선 0 → 옆선 +)
y = 길이 (목 0 → 밑단 +)
```

원문 「내려온다」 → 엔진 **y 증가**, 원문 「나간다」 → 엔진 **x 증가**.
번호점을 옮길 때 이 대응을 매번 확인할 것. 도면을 눈으로 따라 읽으면 축이 뒤집힌다.

### 못 읽은 것 · 본문에 없는 것 (전수 대조 · 2026-08-13)

번호점을 전수로 훑어 **본문이 정의하지 않고 쓰기만 하는 번호**를 뽑았다.
1~78(몸판) · 1~26(소매) 중 **아예 안 나오는 번호는 없다.**

| 번호 | 상태 | 처리 |
|---|---|---|
| **18** | 「17-18 연결」만 있고 정의 없음 | 17번에서 밑단까지 내린 점으로 읽음 (도면 일치) |
| **45 · 46** | 작도점이 아니라 **∥ 같은치수 표시** | 검산용 — 조각에는 안 그린다 |
| **58** | [39][40] 이 쓰는데 **정의가 없다** | 앞 절개선이 암홀에서 출발하는 점. 도면상 30번의 앞판 대응 위치 ⚠ |

**규칙이 모호한 곳 — 엔진에서 결정해야 한다**

- ~~**38 · 39**~~ **해결** (노이즈 제거본 · 2026-08-13) — **다트 다리의 직선 연장**이다.

  ```
  38 = 33→36 직선을 밑단까지 연장
  39 = 32→36 직선을 밑단까지 연장
  ```

  도면에서 초록선(33 쪽)이 밑단 **38**(안쪽)에, 빨간선(32 쪽)이 **39**(바깥)에 닿는다 —
  두 다리가 36번을 지나며 **자리를 바꾼다**. 즉 다트가 36번(H선 위 5) 아래에서
  다시 벌어져 밑단까지 가는 **다이아몬드 다트**이고, 이게 치마폭을 만든다.

  ★ 36번이 34번 바로 아래에 있으므로 **38·39 의 2등분은 대수적으로 35번과 정확히 같다.**
  원문의 「38~35 치수를 재서 35번에서 그만큼 밖으로 = 39」는 새 규칙이 아니라
  **이 구조가 맞는지 확인하는 검산**이다. 엔진은 직선 연장 한 번으로 끝난다.
- **44** : 「직각이 만나는 점」 — 밑단이 옆선과 90° 로 만나도록 하는 보정점.
  도면에서 40번 바로 옆(살짝 위)에 ⌐ 기호로 찍혀 있다.

**표시일 뿐 작도점이 아닌 것** — `A`(다트분 참고 치수) · `★`(유차 같은치수) ·
`■`(소매 이세 확인선) · `직각` · `1`(암홀↔등품선 간격) · `2`(어깨 내림) · `∥`(45·46)

### ★ 도면을 세우고 나서 드러난 것 3가지

**1. 「어깨를 수정합니다」[13] 는 말이 아니라 계산 단계다.**
21번을 어깨/2(19) 자리에 찍고 2 내려와 22번을 잡으면, 2~22 를 재었을 때
`√(19² + 2²) = 19.105` 로 **어깨/2 를 넘는다**. 원문이 「재서 확인하고 수정하라」는 게
이것이다. 엔진은 처음부터 맞춰야 한다:

```
x₂₂ = √( (어깨/2)² − 2² ) = √(361 − 4) = 18.894
```

**2. 어깨/2 는 어깨 솔기 길이가 아니다.**
`어깨/2` 는 **2번(뒤목중심) ~ 22번(어깨점)의 직선**이다. 실제 어깨 솔기는

| | 55 Size |
|---|---|
| 2~22 (어깨너비/2) | 19.00 |
| **20~22 (어깨 솔기)** | **12.72** |
| 20~23 (다트 포함) | 14.22 |

[33] 의 「뒤 다트분을 뺀 2분의어깨길이를 맞추어」는 **앞 어깨 솔기 = 12.72** 라는 뜻이다.
19 로 읽으면 어깨가 6 이상 길어진다.

**3. 12번 — 괄호값이 오타다.** (고해상도 확인 · 해결)
[7] 은 「**4분의유B 더하기 1.5** 나간곳(**22.5cm**)」인데 유B/4 = 21.5 이므로 식대로면 **23.0** 이다.
고해상도 도면의 12번 라벨도 **`유B/4 + 1.5`** 라 **식이 둘, 괄호값이 하나**다.
→ **23.0** 을 쓴다 (완성 가슴둘레 92 · 여유 6).

**⚠ 새로 잡힌 불일치 — 16→17 (H선 여유)**
[9] 본문은 「여유분 **1.5**cm 더 나간곳에 17번」인데, **도면에는 `↑1` 로 적혀 있다.**
W선은 도면·본문 모두 `↑1.5(여유)` 로 일치하는데 H선만 다르다.

| | 본문 | 도면 |
|---|---|---|
| W 여유 (13→14) | 1.5 | **1.5** ✓ |
| H 여유 (16→17) | 1.5 | **1** ✗ |

H 여유가 1 이면 완성 엉덩이둘레 = 90 + 4 = **94**, 1.5 면 **96** 이다.
도면 쪽(1)이 W 여유(1.5)보다 작은 것도 자연스럽다 — 엉덩이는 덜 조인다.
**K 로 빼 두고 기본은 도면값 1.0** 으로 간다.

**4. 24번 = 뒤중심선이 진동선과 만나는 점** (2026-08-13 사용자 확인 · 해결)
처음엔 24번을 못 읽어 등품선 높이를 「진동깊이의 1/2」로 가정했는데, **틀렸다**.
24번은 [6] 에서 그린 **등솔선(8→9 곡선)이 진동선을 자르는 점**이다. 그러면

```
24 = (뒤중심곡선(y=BL), BL)          55 Size → (0.31, 21)
25 = 5~24 의 2등분                    → (0.15, 21)
26 = 25 + 등품/2                      → (17.15, 21)
```

**즉 25·26·28·29 는 모두 진동선(y=21) 위에 있고, 등품선은 「세로선」이다** —
26 에서 27(y=0)까지 올라간다. 도면에서 이 점들이 진동 세로선 위에 나란히 찍힌 것도
세워 놓고 보면 「진동선 위에 x 만 다른 점들」이라 앞뒤가 맞는다.

⚠ **등품/2 는 뒤중심(x=0)이 아니라 25번에서 잰다.** 그래서 등품선이 x = 17 이 아니라
**17.15** 다. 0.15 는 등솔선이 진동선에서 이미 나가 있는 양의 절반이다.
작지만 등품·암홀·절개 통과점(29)이 전부 여기에 매달려 있으므로 식으로 두어야 한다.

### 뒤 다트·절개선

## Ⅳ. 소매 — 한 장 소매로 두 장 느낌 (점 1~26)

### 필요치수

| 항목 | 값 |
|---|---|
| 소매통 | 55~66 = **33~34** · 77~88 = 35~36 |
| 소매부리 | **24** (자켓이면 55~66 = 26 · 77~88 = 27 · 99 = 28) |
| 소매길이 | **56** |
| 소매산 | **AH/3** |

> **소매통 정하는 법** — 앞뒤 암홀점을 표시한 뒤 줄자를 겨드랑이로 넣어 팔둘레를 재고
> **4(맞게)~6(여유있게)** 를 더한다.
> 소매통이 **넓으면 소매산을 0.5~1 올리고**, 좁으면 내린다.
> ⚙ 즉 **소매산 높이는 결과가 아니라 조절 손잡이**다 — 바재킷에서 배운 것과 같다
> (「소매통 반폭 = √(암홀² − 수직변²)」).

### 골격

```
[1] 1·2·3·4 보조선
[2] 앞뒤 AH 둘레를 재서 3으로 나눈 뒤, 2번에서 아래로 **AH/3** = 5번 → 진동과 직선 연결
[3] 5번에서 소매산을 향해 사선으로 올라가 **앞AH 치수**가 되는 지점 = 6번
[4] 6번에서 진동쪽으로 자를 대어 **뒤AH 치수**가 되는 곳 = 7번 → 8번과 직선 = **소매통선**
[5] 6번에서 **1.5 앞쪽**으로 들어온 곳 = 9번 → 10번과 직선 = **소매중심선**
[6] 10~11 을 2등분하여 12번 → 12번에서 **2~2.5 올라간** 13번에 자를 대고 **EL(팔꿈치선)**
```

> ⚙ **소매산 곡선을 「대각선 = 암홀 길이」로 잡는 방식**이다 —
> 5번에서 앞AH 만큼 사선을 그어 6번, 6번에서 뒤AH 만큼 그어 7번.
> 바재킷의 `capGeom` 과 **같은 원리**라 그 코드를 그대로 옮길 수 있다.
> 다만 여기서는 앞뒤를 **따로 두 번** 재므로 halfF·halfB 가 자동으로 갈린다.

### 소매산 곡선

```
[7] 5번에서 **4.5** 나가서 15번
    9번에서 **4.5~5** 들어온 곳 16번
    16번에 곡자를 대고 15번과 곡선 연결
    16-15 를 2등분 = 17번 · 17-15 를 2등분 = 18번
[8] 7번에서 **4** 들어와서 19번
    9번에서 **4.5~5** 나가서 20번
    20번에 곡자를 대고 **거의 직선에 가까운 곡선**으로 19번과 연결
    20-19 를 2등분 = 21번
[9] AH라인은 9번에 암홀자를 놓고 **앞쪽부터** 그린다
    그려진 암홀을 재서 **앞·뒤 암홀 + 이세 1.5~2** 가 나오는지 확인
```

> ⚙ **이세 1.5~2** 가 이 소매의 검산 조건이다(재킷은 3~4).
> 원피스는 패드가 없으므로 이세가 작다.

### 소매부리·중심선

```
[10] 3번에서 **소매부리 (24)** 나간 곳 = 22번
[11] 22~8 을 2등분하여 23번 → 나머지 한등분(23~8)만큼 3번에서 **밖으로** = 24번
[12] 5번에 곡자를 대고 24번과 연결하여 곡선
[13] 7번과 23번도 같은 방법으로 곡선
[14] EL 선에서 **1 아래**에 25번 → 곡선으로 14번과 연결 = **MP 시킬 분량선**
[15] 10번에서 안쪽으로 **반인치 (1.25)** 들어온 곳 = 26번
     11번에 곡자를 대고 26번과 곡선 연결하여 **중심선을 틀어준다**
     23·24 를 **0.5 내려** 소매부리를 곡선으로
     ■ 24~5 선 치수 + **이세 0.5** 를 23~7 ■ 선에서 확인하고,
       남는 분량은 **25번 MP 분량에 포함시켜 줄인다**
```

> ⚙ **「한 장으로 두 장 느낌」의 정체가 [14][15] 다.**
> 팔꿈치 아래를 MP(접어 없앰)로 줄이고 중심선을 1.25 틀어, 한 장인데도
> 두 장 소매처럼 앞으로 굽는다. 엔진에서는
> ① 24~5 와 23~7 의 **길이 짝**을 맞추고 ② 남는 양을 MP 분량으로 넘기는
> **이분법 풀이**가 필요하다 — 바재킷 소맷부리 몫과 같은 구조다.

## Ⅴ. 제도 순서 (의존 그래프)

엔진은 이 순서로 계산해야 한다. **화살표는 「없으면 못 그린다」** 는 뜻이다.

```
치수 ──▶ ① 기본선 (2·5·6·7·3 · 8 · 9·10·11)

             ├─▶ ② 뒤판 옆선 골격 (12 · 13·14·15 · 16·17)

             │        │  ※ [13] 어깨 = 어깨/2 + 다트분 확인
             │        ▼
             ├─▶ ④ 등품·암홀 (25·26·27 · 28·29 · 42 → AH)
             │        ▼
             └─▶ ⑤ 뒤 다트·절개 (30·31 · 32·33·34·35 · 36 · 37)
                      │  ※ 30-29-32 는 한 줄기 스플라인
                      ▼
                  ⑥ 밑단 보정 (38·39·40 → 43·44·45·46)
                      │  ※ 다트를 접었을 때 밑단이 안 벌어지게 「재서 그만큼 밖으로」
                      ▼
                  ⑦ 뒤판 완성 ──┐
                                 │  (복사)
                                 ▼
                  ⑧ 앞판 올림 (47·49 = 유차만큼) → 앞품 51·52 → 목 53·54 → 어깨 56·57
                      │  ※ [33] 앞 어깨 = 뒤 어깨 − 다트분  ← 봉제 짝
                      ▼
                  ⑨ BP·앞 다트 (59·60 · 61·62(MP) · 63 · 66 · 68·69)
                      ▼
                  ⑩ 앞 암홀·절개 (70 · 71·72 · 73·74 · 75·76 · 77·78)
                      ▼
                  ⑪ 앞판 완성 (44 직각 → 밑단)
                      │
                      ▼
                  ⑫ AH 확정 (앞AH + 뒤AH)
                      ▼
                  ⑬ 소매 (AH/3 → 5 → 6(앞AH) → 7(뒤AH) → 소매통선)
                      ▼

                      ▼

```

**핵심 의존 3개** — 이 순서를 어기면 값이 꼬인다.

1. **다트분은 옆선 다음에 나온다.** 상수로 먼저 박으면 안 된다 ([8] · [36]).
2. **앞판은 뒤판이 끝나야 시작된다.** 어깨([33])와 옆선 형태를 뒤판에서 가져온다.
3. **소매는 앞뒤 암홀이 확정돼야 시작된다.** AH/3 · 앞AH · 뒤AH 를 모두 쓴다.

### 스위트 규칙 (다른 9개 모듈과 같게)

- 조각은 **폐곡선** · 점 간격 **0.015~0.06** · 골선은 직선 · 내부선 ≥1 · 너치 ≥1
- 너치는 재단선 위에 있고 틱이 조각 **안쪽**을 향한다
- 전 호수(44~88) **단조성** — armholeTotal · neckBack · neckFront
- **UI 계약** — STYLE_KEY 는 전부 출력을 바꿔야 한다
- 조각별 너치 개수가 **호수마다 같아야** 한다
  (⚠ 바재킷에서 이걸로 버그를 잡았다 — 고정 cm 절개 위치가 44호에서만 너치를 옮겼다)

### 바재킷에서 배운 것 — 미리 피할 함정

1. **비율로 잡을 것을 고정 cm 로 박지 말 것.** 호수가 커지면 그 값이 차지하는 비율이
   달라져 조각이 호수마다 다르게 나온다. (`twoSideOff` · `twoFrontHemIn` 사고)
2. **봉제 짝은 빠짐없이 표에 넣을 것.** 두 조각에 걸친 짝(카라 ↔ 뒷목+고지선)이나
   한쪽만 푸는 짝(소매 앞 시임)은 검사에서 잘 빠진다.
3. **곡선의 「휨 방향」을 확인할 것.** 길이만 맞으면 통과하는 검사는 부호가 뒤집힌
   조각을 놓친다. (카라 바깥선 사고)
4. **이분법 구간을 넉넉히, 그리고 gap 함수가 단조인지 확인할 것.**
   양 끝 부호만 보는 이분법은 답이 있는데도 놓친다.
5. **정답지가 있으면 겹쳐서 편차를 재고, 그 상한을 검사에 걸 것.**
