#### 목너비 — **도면 치수를 쓴다** (앞 7.15 · 뒤 6.57 · 2026-08-12)

이 엔진은 PDF 우선이므로 목너비도 도면을 따른다.
교재 [18][23] 은 앞뒤 모두 `B/12 + 1.5`(=8.30)로 **넓게** 판다 — 재킷은 블라우스·니트
위에 겹쳐 입는 옷이라는 이유다. 도면은 그보다 조인다.

| | 도면(우리) | 교재 |
|---|---|---|
| 앞 목너비 | **B/12 + 0.35** = 7.15 | B/12 + 1.5 = 8.30 |
| 뒷목너비 | **B/12 − 0.23** = 6.57 | B/12 + 1.5 = 8.30 |

★ **목너비를 좁히면 어깨선이 길어진다.** 어깨점 x 는 `어깨/2 + 다트분` 으로 고정이라
  목옆점이 안으로 들어온 만큼 어깨가 늘어난다 — 봉제 어깨 11.06 → **12.69**.
  그래서 **앞 절개 어깨 위치(`fCutShF`)를 0.58 → 0.50 으로 다시 맞췄다**
  (도면 앞판 어깨 6.40 ÷ 어깨선 12.69). 목너비를 되돌리면 여기도 되돌려야 한다.

#### 어깨 늘림(패드분) — 뒤판 폭을 도면(20.32)에 맞춘 값

**뒤판 폭을 정하는 것은 어깨점이다** (뒤중심 목점 ~ 어깨점). 도면 20.32 인데
`어깨너비/2(18.60) + 이세(0.75) = 19.35` 라 **0.97** 이 모자랐다.
재킷 어깨는 **패드가 들어가 몸 어깨보다 넓으므로** 이를 「어깨 늘림」으로 모델링했다:

    어깨점 x = 어깨너비/2 + **어깨 늘림 0.97** + 다트(이세)분

⚠ 어깨 늘림·목너비·어깨 다트분은 **모두 어깨선 길이를 바꾼다.** 바꾸면
  **앞 절개 어깨 위치(`fCutShF`)를 다시 맞춰야 한다** (도면 앞판 어깨 6.40 ÷ 어깨선).
  이력: 교재 목너비 0.58 → 도면 목너비 0.50 → 어깨 늘림 넣고 **0.465**.

결과 (55호):

| | 도면 | 엔진 |
|---|---|---|
| 앞판 폭 | 21.04 | **21.04** (차 0.01) |
| 뒤판 폭 | 20.32 | **20.33** (차 0.02) |
| 앞판 어깨 | 6.40 | 6.38 |
| 앞 목너비 · 뒷목너비 | 7.15 · 6.57 | 7.15 · 6.57 |

⚠ 도면이 교재보다 목이 조이므로 **겹쳐 입을 때 목이 끼는지 시착으로 확인할 것.**
  교재값으로 돌리려면 UI 「앞/뒤 옆목 파기」에 1.5, 「앞 절개 어깨 위치」에 0.58.

# 테일러드 재킷 제도법 — 번호점 방식 (출처: 백영례 blog.naver.com/qor1214/100118497514)

**이 문서가 바재킷 작업의 기준이 된다.** 지금까지는 한 호수(DE36) 도면 좌표에
맞추느라 곡선을 앵커로 억지 적합했는데, 여기에는 **계산식이 전부 있어** 전 호수가
따라오는 엔진을 만들 수 있다. 다른 8개 모듈이 다 이 방식이다.

## Ⅲ. 앞판 (20~38단계 · 점 41~72) — **뒤판을 복사해서 그린다**

뒤판 전체를 복사하는 게 아니라 **중요선만 옮겨** 그린다.

```
[20] 진동점 13번에서 **유차 2.5** 올라간 곳 = 41번, 42-43 직각
     2번에서도 **유차 2.5** 올라간 곳 = 44번 → 직선 = 45번
     ※ 「유차」로 표시한 부분들은 치수가 같아야 한다
[21] 43번에서 **앞품/2**(16) = 46번 → 47번 직선 연결
     47번 아래로 **4.5** = 48번 · 46~47 을 3등분 = 49번
[22] 기본목 **B/6**(=7) 23번에서 직선 위 = 50번, **1cm 내려** = 51번
     48-51 연결 = 어깨기울기 안내선 S·N
[23] 2번에서 **어깨/2** 확인 = 52번 · 51번에서 **1.5** = 53번
     ★ 잘라 둔 뒤판을 대고 **뒤 다트분(또는 이세분)을 뺀 어깨 길이가 같은지** 확인
       (51~52 = 뒤판 38~28 치수)
[24] 5번에서 **W/4** = 54번, **여유 1.5~2** = 55번
     41번에서 56번을 향해 곡선, 56~42 자연스럽게 — **뒤판과 같은 형태로 옆라인**
     ※ 곡선을 먼저 그리는 이유: W/4+여유를 뺀 나머지를 다트로 넣는 방법도 있어서.
       앞다트 정해진 치수(2~3)로 먼저 주면 뒤판 옆라인과 많이 달라질 수 있다
[25] 52번에서 암홀 — **49번 앞품에서 0.5 떨어지게**
[26] **유장 25** · **유폭/2 8** → **BP = 57번**
     57번에서 **1.5~2** = 58번 → 직선 내려 59번
[27] 42~16 을 2등분해 59번 양쪽 = 60·61번 · 59번에서 **5cm 위** = 62번
     W선에서 앞다트분을 양쪽으로 = 63·64번
[27b] 41번에서 **5cm 내려** 65번 → BP 향해 선
      59번에서 **유차 2.5 내려** 66번 → BP 향해 선
[28] 67-68 을 연결해 **앞 절개선** 곡선
     ⚠ 46~48 의 2등분점 69번 **위로 올라가면 안 된다** — 69번 아래에서
       선이 가장 자연스럽게 나오는 지점을 찾아 연결
[29] 68-64 · 68-63 연결 · 63-61 · 64-60 연결
[38] 3번에서 **앞처짐 2.5** 내려 = 70번
```

### 앞뒤 옆라인 규칙 (중요)
- 뒤판은 **1.5 후려준 부분부터** H 치수가 나가고, 앞판은 **기본선에서** H 치수가 나간다
- 그래도 **옆라인은 비슷하거나 같게** 그려야 간지나는 옷이 된다
- W 도 마찬가지 — 앞판의 남는 여유분은 **다트로 처리**해 뒤판과 같게
- 앞판 여유분이 **5cm 이상이면 앞 다트를 두 개**로

### 다트 위치 원칙
- 정해진 공식은 없다. 일반적으로 **W 라인을 3등분한 곳**이 무난
- **안쪽으로 들어올수록 타이트, 밖으로 나갈수록 넉넉**

## Ⅴ. 패널 구성 — **이미 본문에 다 있다** (다음 페이지 불필요)

원문 마지막이 「패턴분리와 보정은 다음페이지에 계속」으로 끝나지만,
**분리 자체는 이미 본문에 있다.** 앞뒤판 합성 그림에
「뒤패널1」「뒤패널2」「앞패널1」「앞패널2」 라벨이 붙어 있고 본문이 그 선을 그린다:

- **뒤 절개선** [16] — 암홀쪽에서 **27번(다트 중심선)** 을 향해 그린다.
  27-32 곡자 · 32-31 연결(뒤패널1) · 33-30 연결(뒤패널2)
  ⚠ **26번 위로 올라가면 안 된다**
- **앞 절개선** [28~29] — **67-68 연결**.
  ⚠ 46~48 의 2등분점 **69번 위로 올라가면 안 된다**
  68-64 · 68-63 연결 → 63-61(앞패널1) · 64-60(앞패널2)

### ★ 이 제도법은 **앞뒤 각 2장 = 4패널**이다

```
앞패널1 (앞중심·라펠) | 앞패널2 (암홀·BP)  ‖  뒤패널2 (암홀) | 뒤패널1 (뒤중심)
                                  ↑ 옆선
```

**Barjacke(sisterMAG) 와 구성이 다르다.** Barjacke 는 앞판·앞옆판·**옆판**·뒤판 이고
옆판이 겨드랑을 품어 옆선을 흡수한다. 이 제도법은 **옆선이 그대로 있다.**

→ **우리 `토르소원형프린세스라인` 과 같은 구조다.** 검증된 조립 코드를 그대로 쓸 수 있고,
  「옆판을 옆선 가로질러 붙이기」(`backToFrontTf`)가 **필요 없어진다.**
  Barjacke 식 옆판이 필요하면 나중에 응용으로 얹는다.

### 원문이 애매해 판단한 자리 (근거를 남긴다)

1. **67·68번이 원문에 정의되어 있지 않다.** 앞 절개선을 「67-68 연결」이라고만 한다.
   → **암홀(49번 높이) → 58번(다트 중심) → 63·64번 → 29번 → 60·61번** 으로 놓았다.
   BP 를 그대로 지나게 해 보았더니 두 다리가 58번 기준으로 비대칭이라
   **짝 길이가 0.37 어긋났다.** 58번을 지나면 좌우가 거울상이 되어 저절로 맞는다.
   (실무에서도 절개선은 BP 를 살짝 비껴 지난다.)

2. **65~66 의 「유차 2.5」가 무엇을 없애는가.**
   [20] 대로 앞 상단선과 겨드랑을 유차만큼 올리면 **앞 옆선이 뒤보다 정확히 유차만큼
   길어진다.** 65→BP · 66→BP 두 선 사이가 그 길이를 먹는 **가슴다트**다.
   접으면 앞뒤 옆선이 같아진다 — `engine-verify` §2 가 전 호수에서 이걸 잰다.
   다트를 닫으면 BP 아래가 회전하므로, 그 회전이 곧 **절개선으로의 다트 이동**이다.

3. **다트 꼭짓점은 57번(BP)이 아니라 58번**으로 두었다. BP 를 축으로 돌리면
   절개선이 지나는 58번이 함께 돌아 **다트 위 구간과 0.16 어긋나 폐곡선이 끊긴다.**
   실무에서도 다트 끝은 BP 에서 1.5~2 물러난다.

4. **밑단**. 원문은 H선(3번)에서 끝난다. 재킷은 그보다 길어야 하므로
   **밑단 = 옷길이 + 재킷 길이 추가**로 두고, H 치수(H/4 + 여유)를 그 밑단 자리에서 쓴다.
   엉덩이선은 안내선·너치용으로 따로 그린다.

5. **「자연스럽게 · 원하는 곳」은 전부 스타일 옵션**으로 뺐다 —
   옆선 허리 들임 · 뒤 절개 위치 · 옆목 파기 · 여밈 겹침 · 고지선 길이 · 카라 넓이 등 11개.
   `suite-verify.js` 의 UI 계약 검사가 「입력란이 실제로 동작하는가」를 전 키에 건다.

6. **카라**는 **몸판 목둘레를 펴서** 만든다 — 테일러드 카라의 정석대로 몸판 위에
   꺾임선을 축으로 그려 떼어내는 것과 같은 결과다 [42]~[46].
   뒷목둘레 + 고지선을 한 줄기로 이어 **(호길이, 방향변화)** 수열로 바꾸고,
   방향변화만 `K.collarSpring` 배로 줄여 다시 적분한다. 길이는 손대지 않으므로
   목둘레와 **정확히** 같고, 휨 분포는 목선을 물려받아 뒷목 쪽은 굽고 고지선 쪽은
   곧은 실제 카라 모양이 된다. 바깥선은 목붙임선을 카라넓이만큼 바깥으로 민 선이다.

   ⚠ **예전 판은 「길이만 맞춘 원호」였다.** 그래서 라펠·꺾임선·고지선·목너비를
   아무리 바꿔도 카라가 꿈쩍하지 않았다(늘림 0.2653 고정). 지금은 따라온다 —
   고지선을 부풀리면 16.93 → 18.82, 노치를 깊게 하면 20.45 로 목붙임선이 움직인다.
   도면 겹침 편차는 0.44 → **0.43** 으로 유지된다.

   ⚠ **굽히는 방향이 카라의 성격을 정한다.** 회전 중심이 목 쪽이라야 바깥으로
   밀 때 반지름이 커져 길어지고 = **눕는 카라**가 된다. 반대로 굽히면 바깥선이
   오히려 짧아져 목을 조이는 **선 카라**가 된다 — 예전 판이 이 부호를 반대로 두어
   66호에서 바깥선 16.34 < 목붙임선 18.45 였다. 조각만 보면 멀쩡한 띠라 눈으로는
   안 잡힌다. 봉제 짝 검사에서도 카라 짝이 **두 조각(뒤판 뒷목 + 앞판 고지선)에
   걸쳐** 있어 표에서 빠져 있었다. 지금은 `engine-verify.js` §1 이 길이와
   「눕는가」를 같이 본다.

   **늘림의 양은 도면에서 뜬다.** 도면 카라는 목붙임선 17.42 · 바깥선 17.66 —
   늘림이 +0.24 뿐이다. 도면의 식서 화살표가 골선과 약 57° 로 놓여 있어
   **바이어스 재단 언더칼라**이기 때문이다(바이어스는 다림질로 바깥선을 늘려 쓴다).

   이 엔진은 도면이 먼저이므로 **fall × 0.07**(= +0.27)로 둔다. 검사도 하한
   (바깥선 ≥ 목붙임선)만 건다.

### 소맷부리 몫 — 두 짝을 같이 풀어야 했다 (2026-08-13)

도면 55호는 큰 14.24 / 작은 11.16 (몫 0.561). 엔진은 0.593 이었고, 더 나쁜 건
**호수마다 몫이 널뛴 것**이다 — 44호 0.532 → 88호 0.706. 작은소매 부리가
11.27 에서 7.86 으로 **줄었다**. 커질수록 좁아지는 소매다.

원인이 셋이었다.

1. **부리 앞 모서리가 `halfF − 상수`** 였다. halfF 는 호수마다 3 씩 커지는데 상수를
   빼면 모서리가 halfF 를 그대로 따라가 큰소매만 넓어진다. **비율**(`twoFrontHemAt`)로 바꿨다.
2. **부리 뒤 모서리는 아무도 안 맞추고 있었다.** 큰소매 `앞 밑선` ↔ 작은소매 `바깥 뒤선`
   은 서로 꿰매는 짝인데 검사 표에도 없었고 전 호수 0.26~0.39 어긋나 있었다.
   두 밑단 모서리는 서로 독립이므로 **뒤 모서리를 이분법으로 풀어** 맞춘다.
   ⚠ 이 gap 함수는 **단조가 아니다** — 어느 쪽으로 밀어도 곡선이 길어져 양 끝 부호가 같고

   훑어서 부호가 바뀌는 구간을 찾은 뒤 그 안에서만 이분법을 건다.
3. **몫 이분법 구간이 좁았다**(0.35~0.90). 44호에서 답을 놓쳐 대비값 2/3 으로 떨어졌고,

전부 0.26 안이다. 겹침 7.89 · 단추열 3.71 · 간격 9.80 · 구멍 2.09 는 예전 판이
이미 이 도면에서 뜬 값이라 손댈 게 없었다.

⚠ 도면의 단추 세로 간격은 **일정하지 않다** — 단추 기준 9.81 / 9.52, 구멍 기준
9.82 / 9.68. 엔진은 9.80 균일이다. §4 허용을 0.35 로 잡아 그 범위를 덮는다.

**검사를 고쳤다.** 예전 §4 는 `K.overlap` 과 `K.btnGapY` 를 숫자 리터럴과 견주고
있었다 — 같은 값을 두 번 적은 것이라 자리가 틀어져도 못 잡는다. 지금은
**조각에 실제로 찍힌 단추·구멍 좌표**를 도면 표시와 맞춰 본다.

### 주머니 — 위치는 도면에 없다 (2026-08-13)

몸판 4장의 내부선을 전부 뒤졌지만 **주머니 표시가 하나도 없다.**

| 조각 | 도면에 그려진 내부선 |
|---|---|
| 앞판 | 단추 자리 6개 (y 27.24 / 36.92 / 46.74 두 줄) · 너치 1 |
| 앞옆판 | 가슴다트(1.21 × 20.47) · 다트 연장선 · 허리선 · 너치 3 |
| 옆판 | 절개 표시 · 너치 |
| 뒤판 | 트임선(10.31) · 너치 3 |

그래서 `pocketFromWL`(허리선 아래 6.2)·`pocketTilt`(6°)는 **도면 근거가 없는 관례값**이다.
매거진 패턴이 위치를 봉제 설명서로 넘기는 흔한 방식이다. 근거가 생기기 전에는
바꾸지 않는다 — K 주석에 「도면에 없음」이라고 박아 뒀다.

**조각 크기는 도면에 있어서 맞췄다.** 귀 둥글리기까지 넣었다 — 도면 곡선에 원을
맞춰 반지름을 실측했다.

| | 이식판 | 지금 | 도면 |
|---|---|---|---|
| 플랩 | 14.30 × 6.30 (각짐) | **15.70 × 5.70 · 귀 1.99 / 0.73** | 다는변 15.71 · 깊이 5.25~5.69 |
| 플랩 넓이 / 둘레 | 90.1 / 41.2 | **88.5 / 41.6** | 88.7 / 42.2 |
| 주머니감 | 15.70 × 15.80 (각짐) | **15.85 × 12.36 · 귀 3.40** | 입구 15.84 |
| 주머니감 넓이 / 둘레 | 248.1 / 63.0 | **190.9 / 53.5** | 190.9 / 53.6 |
| 조각 편차(평균/최대) | — | **0.20 / 0.70 · 0.28 / 0.83** | — |

주머니감이 6.6 깊었다. 도면 주머니감은 입구 15.84 를 **긴 변**으로 눕혀 그려 놓아
bbox(13.69 × 15.75)만 보면 방향을 거꾸로 읽게 된다 — 실제 입구는 15.84 쪽이다.

플랩은 **아랫변(자유변) 두 귀만** 둥글고 다는변 쪽은 각져 있다. 두 귀의 반지름이
1.99 와 0.73 으로 다른데 도면에 앞뒤 표시가 없어, 기울기가 「앞이 올라간다」인 것에
맞춰 큰 쪽을 앞으로 두었다. 둥글린 만큼 넓이가 줄어 깊이를 5.60 → 5.70 으로,
주머니감 깊이를 12.00 → 12.36 으로 올려 넓이를 도면에 다시 맞췄다.

### 안단 구현 (원문 「안단선」 절)

- **앞 안단** — 몸판에서 떠낸다. 바깥 변(고지선·라펠 윗변·라펠선·여밈선·밑단 일부)은
  앞판과 **같은 선**을 쓴다 (검산기가 전 호수에서 짝 길이를 잰다).
  안단선은 `밑단 6.5` → **가슴선 높이에서 꺾임선 안쪽 2.5** → `어깨 4.5` 를 지나는 곡선.
  ★ 가운데 통과점이 핵심이다 — 안단이 **라펠을 덮어야** 뒤집었을 때 겉감이 안 보인다.
  ★ 원문 「안단선은 앞 절개선 위쪽을 지나 어깨로 올라간다」는 곧 **안단선이 앞판 안에
    있어야 한다**는 뜻이다. 엔진이 point-in-polygon 으로 확인하고 벗어나면 경고한다.
- **뒤 안단** — 뒷목선을 안쪽으로 `5.0` 민 띠. 뒤중심 ~ 어깨(4.5)까지.

### 앞판 도면 대조 (2026-08-12 · `barjacke-36-groundtruth.json` 실측)

라펠·노치 자리는 교재가 「원하는 곳」으로만 적어 둔 자리라, **도면에서 규칙을 읽어** 넣었다.
도면은 조각 자체 좌표(왼쪽 끝 = 여밈 끝 · 위 = 목옆점)이고 앞중심은 x 7.974 다.

| | 도면 | 엔진 55호 |
|---|---|---|
| 여밈 겹침 | 7.97 | 7.89 |
| **노치 V 바닥** | **앞중심선 위(x 0)** · 목옆점 아래 6.24 | 같음 |
| **라펠 꼭짓점** | 앞중심 **바깥 3.71** · 목옆점 아래 2.55 | 같음 |
| 고지선 | 현에서 **1.20 아래로 굽음** | 같음 |
| 꺾임 시작(라펠선 ↔ 여밈선) | 조각 위에서 20.1 (맨 윗단추보다 **7.1 위**) | 20.14 |
| 단춧구멍 y | 27.24 / 36.92 / 46.74 | 27.24 / 37.04 / 46.84 |
| 단춧구멍 x | 앞중심에서 3.90~5.99 | 3.71~5.80 |

★ 노치를 **길이·각도**로 잡으면 목너비가 호수마다 달라질 때 V 바닥이 앞중심을 벗어난다
(55호에서 2.86 안쪽에 있었다). 도면처럼 **앞중심 기준**으로 잡아야 한다.

#### 앞 절개선 출발 — **도면 구성(어깨)을 기본으로** (2026-08-12 사용자 결정)

교재 [28] 은 앞 절개가 **암홀**에서 출발한다(69번 아래). 도면(Barjacke)은 **어깨**에서
출발해 앞판이 좁다 — 실측 목옆점에서 **6.40**(어깨길이의 0.58).
도면 구성을 기본(`K.fCutAt = 'shoulder'`)으로 두고, 교재 구성은 `opt.fCutAt = 'armhole'`.

어깨 출발이면 **앞판에 암홀이 없다** — 어깨선 일부만 갖고 암홀은 통째로 앞옆판 몫이다.
안단·안감도 같은 구성을 따른다.

| | 도면 | 엔진 55호 (어깨 출발) | 참고: 암홀 출발 |
|---|---|---|---|
| 앞판 폭 | 21.04 | **22.23** (+1.2) | 26.60 (+5.6) |
| 앞판 어깨 | 6.40 | **6.41** | — (어깨 전체) |
| 앞옆판 높이 | 63.33 | **63.73** (+0.4) | 52.30 (−11.0) |

남는 폭 차 1.2 는 **앞 목너비**다 — 우리는 `B/12 + 옆목 파기 1.5 = 8.30`,
도면은 앞중심에서 7.15. 높이 차 1.6 은 재킷 길이(옷길이 + 6)와 앞처짐 때문이다.

#### 앞 목너비 — **교재값(8.30)을 쓴다** (2026-08-12 사용자 결정)

도면 7.15 로 맞춰 봤다가 **되돌렸다.** 이유:

- **재킷은 안에 블라우스·니트를 겹쳐 입는 옷**이다. 목을 넓게 파야 목이 안 끼고
  안쪽 옷의 목선이 눌리지 않는다. 도면 7.15 는 그만큼 목이 조이는 제도다.
- 교재값이라야 [23] 「52번 = 어깨/2 확인」도 맞는다 —
  앞 어깨점 18.71 vs 어깨너비/2 18.60 (차 0.11).
  도면값이면 어깨 길이가 뒤판에서 정해지므로 어깨점이 **1.04 안쪽**으로 들어간다.

| | 교재 1.5 (기본) | 도면 0.35 |
|---|---|---|
| 앞 목너비 | **8.30** | 7.15 |
| 앞 어깨점 x (어깨/2 18.60) | **18.71** | 17.56 |
| 앞판 폭 (도면 21.04) | 22.23 | 21.08 |
| 고지선 · 카라 목붙임선 | 10.71 · 20.02 | 9.85 · 19.15 |

→ **앞판 폭 1.19 차이는 의도한 차이다.** 도면대로 좁히려면 UI 「앞 옆목 파기」에 0.35.
   `frontNeckOut` 키는 앞뒤를 따로 줄 수 있게 남겨 두었다 (뒤는 `neckOut`).

#### 뒤 목너비도 **교재값(B/12 + 1.5)** 을 쓴다 (2026-08-12 사용자 결정)

같은 이유다 — 재킷은 겹쳐 입는 옷이라 목을 넓게 판다.

| | 교재(우리) | 도면 |
|---|---|---|
| 뒷목너비 | **B/12 + 1.5** (55호 8.30) | 6.57 |
| 앞 목너비 | **B/12 + 1.5** (55호 8.30) | 7.15 |

도면은 앞뒤 모두 교재보다 좁고, 뒤가 앞보다 더 좁다 — 목이 조이는 제도다.
**앞뒤를 같은 1.5 로 두면 목옆점이 앞뒤 한 점에서 만나** 목둘레가 매끄럽게 이어진다.
⚠ 도면 대조에서 목이 넓게 나와도 **고치지 말 것.** 세 곳(K 주석·이 문서·이어서-할-일)에
  같은 결정을 남겨 두었다.

⚠ `engine-verify` §2 의 [28] 검사는 **암홀 출발일 때만** 건다. 어깨 출발에서는
   대신 「절개 시작점이 어깨선 위에 있는가(두 조각의 어깨가 이어지는가)」를 본다.
