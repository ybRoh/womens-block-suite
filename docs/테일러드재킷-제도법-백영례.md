# 테일러드 재킷 제도법 — 번호점 방식 (출처: 백영례 blog.naver.com/qor1214/100118497514)

**이 문서가 바재킷 작업의 기준이 된다.** 지금까지는 한 호수(DE36) 도면 좌표에
맞추느라 곡선을 앵커로 억지 적합했는데, 여기에는 **계산식이 전부 있어** 전 호수가
따라오는 엔진을 만들 수 있다. 다른 8개 모듈이 다 이 방식이다.

> 원문은 55 Size 로 설명한다. 번호점(1~83)을 순서대로 찍어 가는 방식이고,
> **뒤판을 먼저 그린 뒤 복사해서 앞판을 그린다.**

---

## 필요치수 (55 Size · cm)

| 항목 | 값 | 파생 |
|---|---|---|
| 등길이 | 38 | |
| 어깨너비 | 38 | 어깨/2 = 19 |
| 소매길이 | 56 | |
| 등품 | 34 | 등품/2 = 17 · **Size 별 0.5 씩 증가** |
| **B** (상동·윗가슴둘레) | 84 | B/4 = 21 · **B/12 = B/6도 = 7** |
| **유B** (유상동·젖가슴둘레) | 86 | 유B/4 = 21.5 |
| 앞품 | 32 | 앞품/2 = 16 |
| 유장 | 25 | 55"=25 · 66"=25.5 · 77"=26 |
| 유폭 | 16 | 유폭/2 = 8 |
| W (허리) | 68 | W/4 = 17 |
| H (엉덩이) | 90 | H/4 = 22.5 |
| **유차** | 2.5 | 55"·66"=2.5 · 77"·88"=**2.8** (B 90 이상이면 2.8) |

### 체형 참고
- **뒤품이 앞품보다 1.5 많은 것이 정상**
- 굴신체(뒤가 굽음) → 뒷길이를 앞길이보다 2 길게
- 반신체(앞이 제껴짐) → 앞길이를 뒷길이보다 2 길게

### ★ 절개선 두 방식 — 우리 모듈 이름과 같다
- **프린세스라인** : 어깨에서 절개선이 들어감
- **암홀라인** : 진동선(겨드랑)쪽에서 절개선이 들어감

## Ⅰ. 기본선 (1~9번)

```
[1] 1·2·3 보조선을 긋는다 (2 = 우측 상단 기준점)
[2] 2번에서 아래로 B/4 + 1.5 (=22.5)  → 4번 = **진동선**
[3] 2번에서 아래로 등길이 (38)        → 5번 = **W선**
[4] 5번에서 아래로 엉덩이길이 18~20   → 3번 = **H선**
[5] 2~4 를 3등분한 위쪽 점            → 6번
    4·5·3 번에서 각각 1.5 씩 나간 곳  → 7·8·9번   (뒤중심 들임)
```

## Ⅱ. 뒤판 (6~19단계 · 점 10~40)

```
[6]  6-8 을 곡자로 등솔선, 8-9 는 직선
[7]  4~7 의 2등분점 = 10번
     10번에서 **등품/2** 나간 곳 = 11번 → 직선 위로 = 12번
     10번에서 **유B/4 + 1.5~2** 나간 곳 = 13번 → 직선 아래로 = 14번
[8]  9번에서 **H/4** = 15번, **여유 1.5** 더 = 16번
[9]  8번에서 **W/4** = 17번, **여유 1.5~2** = 18번
     13번에서 W 쪽으로 곡선 — H 라인과 자연스레 이어지는 지점이 19번
     **18~19 사이가 W 다트분**  ← 다트분을 「남는 양」으로 역산한다
[10] 2번에서 **어깨/2** = 20번, **다트 1.5** 더 = 21번
     12번에서 **어깨기울기 1.3~1.5** 내려 = 22번
[11] 2번에서 **B/12**(뒤목치수) = 23번, **유차 2.5** 올라간 곳 = 24번, 직각 = 25번
[12] 22-24 사선 = 어깨기울기 안내선 S·N
     2~21 을 재서 어깨/2 + 다트 1.5 를 확인
     ※ 뒤 어깨다트가 싫으면 **이세분 0.7~0.8** 로 대신한다
[13] 22~11 의 2등분점 = 26번
     21번에서 암홀선 — **26번 등품에서 0.5~1 떨어지게**
[14] 11번에서 **2~3 안쪽** = 27번 → 직선 내려 28번, 28번에서 **5cm 위** = 29번
[15] 14~16 을 2등분해 28번 양쪽에 = 30·31번
[16] W 다트분을 양쪽 분배 = 32·33번
     암홀쪽에서 27번(다트 중심선)을 향해 **절개선**을 그린다
     ⚠ **26번 위로 올라가면 안 된다** — 26번에서 시작하거나 내려와야 자연스럽다
     27-32 곡자 · 암홀 절개선의 중심~1/3 지점에 곡자를 대고 33번을 향해 곡선
     32-31 연결(29번이 교차되게) · 33-30 연결(39번이 교차되게)
[17] 암홀쪽 34점에서 다트쪽으로 선 → **MP 0.5~0.8** 접어줄임 = 35번선
[18] 2~23 을 3등분 = 36번, 2번에서 **0.5 내려** 37번
     24번에서 **1.5 나간 곳** = 38번 (옆목 파기)
     38-36 을 암홀자로 곡선 = 뒷목선
     ※ 목이 짧거나 굵으면 2번에서 0.7~1 더 판다
[19] 38~22 2등분 = 39번(다트 중심), **다트길이 7** 내린 점 = 40번
```

## Ⅲ. 앞판 (20~38단계 · 점 41~72) — **뒤판을 복사해서 그린다**

뒤판 전체를 복사하는 게 아니라 **중요선만 옮겨** 그린다.

```
[20] 진동점 13번에서 **유차 2.5** 올라간 곳 = 41번, 42-43 직각
     2번에서도 **유차 2.5** 올라간 곳 = 44번 → 직선 = 45번
     ※ 「유차」로 표시한 부분들은 치수가 같아야 한다
[21] 43번에서 **앞품/2**(16) = 46번 → 47번 직선 연결
     47번 아래로 **4.5** = 48번 · 46~47 을 3등분 = 49번
[22] 기본목 **B/6**(=7) 23번에서 직선 위 = 50번, **1cm 내려** = 51번
     48-51 연결 = 어깨기울기 안내선 S·N
[23] 2번에서 **어깨/2** 확인 = 52번 · 51번에서 **1.5** = 53번
     ★ 잘라 둔 뒤판을 대고 **뒤 다트분(또는 이세분)을 뺀 어깨 길이가 같은지** 확인
       (51~52 = 뒤판 38~28 치수)
[24] 5번에서 **W/4** = 54번, **여유 1.5~2** = 55번
     41번에서 56번을 향해 곡선, 56~42 자연스럽게 — **뒤판과 같은 형태로 옆라인**
     ※ 곡선을 먼저 그리는 이유: W/4+여유를 뺀 나머지를 다트로 넣는 방법도 있어서.
       앞다트 정해진 치수(2~3)로 먼저 주면 뒤판 옆라인과 많이 달라질 수 있다
[25] 52번에서 암홀 — **49번 앞품에서 0.5 떨어지게**
[26] **유장 25** · **유폭/2 8** → **BP = 57번**
     57번에서 **1.5~2** = 58번 → 직선 내려 59번
[27] 42~16 을 2등분해 59번 양쪽 = 60·61번 · 59번에서 **5cm 위** = 62번
     W선에서 앞다트분을 양쪽으로 = 63·64번
[27b] 41번에서 **5cm 내려** 65번 → BP 향해 선
      59번에서 **유차 2.5 내려** 66번 → BP 향해 선
[28] 67-68 을 연결해 **앞 절개선** 곡선
     ⚠ 46~48 의 2등분점 69번 **위로 올라가면 안 된다** — 69번 아래에서
       선이 가장 자연스럽게 나오는 지점을 찾아 연결
[29] 68-64 · 68-63 연결 · 63-61 · 64-60 연결
[38] 3번에서 **앞처짐 2.5** 내려 = 70번
     **앞여밈분** 나가서 71번 → 위로 = 72번선
     앞여밈분 = 얇은 원단 **2** · 두꺼운 원단 **2.5**  (더블은 더 크다)
```

### 앞뒤 옆라인 규칙 (중요)
- 뒤판은 **1.5 후려준 부분부터** H 치수가 나가고, 앞판은 **기본선에서** H 치수가 나간다
- 그래도 **옆라인은 비슷하거나 같게** 그려야 간지나는 옷이 된다
- W 도 마찬가지 — 앞판의 남는 여유분은 **다트로 처리**해 뒤판과 같게
- 앞판 여유분이 **5cm 이상이면 앞 다트를 두 개**로

### 다트 위치 원칙
- 정해진 공식은 없다. 일반적으로 **W 라인을 3등분한 곳**이 무난
- **안쪽으로 들어올수록 타이트, 밖으로 나갈수록 넉넉**

## Ⅳ. 테일러드 카라·라펠 (39~43단계 · 점 73~84)

```
[39] 53번에 직각으로 위아래 선 = 73·74번
[40] 71-72 선에서 **W 위로 2.5 이상** 올라간 곳부터 원하는 곳에 **라펠 = 75번**
     ⚠ 75-76 선이 앞중심선(70-44)과 교차하는 지점이 **앞목 파임**이 되고
       살이 보이는 선이므로 W 위로 2.5 이상 올라가야 배꼽이 안 보인다
[41] 53번(어깨선)에서 **2.5 안으로** = 76번
     75번에 자를 대고 76번을 지나게 선 = 77번   ← **꺾임선(roll line)**
[42] 53번에서 **0.5 나간 곳** = 78번
     78~79 = **뒷목치수** · 79~80 = **카라넓이**(원문 7.5cm, 취향)
     ⚠ 위카라 80번이 77번 선 **안으로 들어가면 안 되고** 같거나 나와야 한다
     ★ **테일러 카라는 옆목점에서 0.5 나가서 뒷목선**을 그린다
       (숄카라·윙카라 등 목 뒤로 넘어가는 카라는 목점에서 그린다 — 목점에서
        넘어가면 카라가 선다)
[43] 53번에서 **2.5 내려** = 82번 → 직각 = 83번
     82·83 은 원하는 카라·라펠 모양에 따라 변하는 치수
     **75번과 77번선을 접는다** → 접은 뒤 보이는 선이 실제 카라 모양
     ⚠ 80번과 74번에서 사선으로 내려와 보이는 84번까지는 **직각을 유지**하며 그린다
```

### 카라 붙임 (44~46단계 · 점 85~87)

```
[44] 어깨선 S 와 연결된 **85번점**을 참고해 **어깨와 카라의 거리**를 생각하고
     원하는 위치에 **86번**을 표시한다
     86번에서 **직각으로 3.5cm** 내려온 점 = **87번**
[45] 86번에서 **4cm 내려와** = **83번**
     83-87 을 직각으로 연결 → 이 선이 [43] 에서 먼저 그린 **82-83 선**이 된다
[46] **83-75 연결** → 라펠 완성
```

### 카라 보정 — 접고 펴서 확인한다

- 완성 그림에서 **빨간선이 카라가 뒷목쪽으로 넘어가는 선**이다
- 다른 종이에 **라펠·카라 부분만 복사**한 뒤 뒷목까지의 카라 패턴을 잘라
  **목선에 돌려 맞춰** 카라의 흐름을 관찰하고 수정한다
- 카라의 **72번·82번은 모나지 않게 곡자로 굴려** 수정한다
- ⚠ **카라 부분은 반드시 복사해서 사용** — 몸판 옆목점 53번의
  **카라 안쪽 검은선이 잘리면 안 된다**

### 안단선

- 앞판 안단 : 어깨쪽 **4~5** · 밑단쪽 **6~7**
- 뒤판 안단 : 같은 방식 (그림 참고)
- 안단선은 앞 절개선 위쪽을 지나 어깨로 올라간다

> 원문은 이 뒤에 **패널 분리와 보정** 과정이 이어진다 (다음 페이지).
> 우리 4패널(앞판·앞옆판·옆판·뒤판) 분리가 거기 있을 것이므로 받으면 이 문서에 추가한다.

### ⚠ 옮길 때 지킬 것
- 번호점을 **그대로 변수명**으로 쓰지 말고 의미 이름을 붙인다(p27 → `bDartCenter`)
- 「자연스럽게」「원하는 곳」으로 적힌 곳은 **스타일 옵션**으로 뺀다
  (라펠 75번 위치 · 카라넓이 79~80 · 다트 위치)
- **확인 절차가 제도의 일부다** — [23] 의 「뒤판 어깨선을 대고 길이 확인」은
  우리 검증기의 어깨 짝 검사와 같다. 원문이 시키는 확인은 전부 검사로 넣는다
