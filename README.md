# 여성복 원형 Suite (문화식)

브라우저에서 열면 바로 동작하는 **여성복 패턴 자동 제도 앱**입니다. 서버·인터넷이 필요 없습니다.

## 바로 쓰기
**`여성복원형Suite-포터블.html`** 을 더블클릭하세요. 이 파일 하나만 복사하면 원형 3종이 전부 동작합니다.

## 구성

| 메뉴 | 상태 | 교재 |
|---|---|---|
| **기본원형** | **완성** — 앞판·뒷판 2조각 | 새로운 기본 무다트 앞면원형(시니어) p.31 / 어깨다트 없는 뒷면원형 p.34 |
| **숙녀복 기본원형1** | **완성** — 앞판(가슴다트+허리다트) · 뒷판(허리다트) · 소매 3종 선택 | 숙녀복 기본원형 I p.46 / 반소매 p.47 / 타이트 긴소매·2장소매 p.48 |
| 숙녀복 기본원형2 | 도면 대기 | — |

```
여성복원형Suite/
  여성복원형Suite-포터블.html   ← 배포용 (이것만 복사)
  여성복원형Suite.html          ← 개발용 (앱 파일을 따로 읽음)
  shell.html                    ← 런처 원본
  build.py                      ← 전체 빌드
  기본원형/          engine.js · ui.* · print.* · dxf.js · pdf.js · build.py · 검증기
  숙녀복기본원형1/    engine.js · ui.* · print.* · dxf.js · pdf.js · build.py · 검증기
  숙녀복기본원형2/
  SPEC.md            ← 전체 사양서 · 계산식과 검증 기준의 유일한 기준
```

## 새 원형을 추가하려면
1. 폴더를 만들고 교재 도면 이미지 + DXF 를 넣습니다
2. DXF 를 역산해 계산식을 확정하고 `SPEC.md` 에 기록합니다
3. `기본원형/` 의 `engine.js`·`ui.*`·`print.*`·`dxf.js` 를 복사해 제도 함수만 바꿉니다
4. `build.py` 의 `APPS` 목록에 `(폴더, 탭이름, True)` 를 추가합니다

**원형마다 제도법이 다르므로 엔진을 공유하지 않습니다.** 하나를 고치다 다른 원형이 깨지지 않게 하려는 의도입니다.

## 두 원형의 차이

|  | 기본원형 | 숙녀복 기본원형1 |
|---|---|---|
| 다트 | 없음 (무다트) | 앞 가슴다트 + 앞뒤 허리다트 |
| 앞길이 | 안 씀 (등길이 + 앞내림 1.3) | **입력함** — `앞길이 − 등길이` 가 가슴다트 분량 |
| 폭 | `B/4 + 1.9`(뒤) · `B/4 + 1.5`(앞) | `B/4 + 여유분/2` — **여유분이 사용자 입력** |
| 소매 | 없음 | **반소매 · 타이트 긴소매 · 2장소매**(큰소매+작은소매 2조각) 선택 |
| 66호 B | 87.6 (여유 포함) | 84.0 (교재 필요치수) |

## 기능
- **44 · 55 · 66 · 77 · 88호** 자동 제도 (앞판 · 뒷판 2조각)
- 치수 8개 직접 편집 (비표준 체형 대응). 무다트 원형이라 **앞길이는 쓰지 않습니다** — 등길이에 앞내림 1.3
- **부위별 시접** — 목둘레 1.0 · 어깨선 1.0 · 암홀 1.0 · 옆선 1.5 · 밑단 3.0 · 소매부리 2.5 · 골선 0(고정)
- **PDF 저장 — 배율 고정 1:1** ★권장. `1cm = 28.3465pt` 로 좌표를 직접 찍어 인쇄 대화상자의 배율 설정에 영향받지 않습니다
- **1:1 실물 인쇄** — A4 타일(겹침 10mm · 정합 십자 · 페이지 좌표) / A1 롤 594mm(줄바꿈 자동)
- **5cm 캘리브레이션 눈금** + 인쇄 배율 보정 입력
- **DXF 내보내기** — AC1021 UTF-8, cm/mm, 레이어 7개(완성선·시접선·골선·너치·기준선·식서·문자)
- 라벨 충돌 회피, 봉제 정합성 자가진단

## 인쇄 시 반드시
**PDF 저장을 쓰세요.** 용지 크기와 좌표를 포인트 단위로 직접 박아 넣으므로 배율이 어긋날 수 없습니다.
PDF 뷰어에서 인쇄할 때만 **“실제 크기 / 100%”** 로 두면 됩니다.

브라우저로 바로 인쇄한다면 대화상자의 **“페이지에 맞춤 / 배율 맞춤”을 끄세요.** 켜져 있으면 1:1이 깨집니다.
어느 쪽이든 첫 장의 5cm 눈금을 자로 재고, 다르면 좌측 **인쇄 보정** 칸에 실측값을 넣으세요.

## 소스와 빌드
포터블 파일은 자동 생성물입니다. **직접 수정하지 마세요.**

| `기본원형/` 안의 파일 | 담당 |
|---|---|
| `engine.js` | 제도 엔진 (치수 → 조각 좌표) |
| `ui.html` `ui.css` `ui.js` | 화면 |
| `print.js` `print.css` | A4 타일 / A1 롤 출력 |
| `dxf.js` | DXF 내보내기 |
| `pdf.js` | PDF 내보내기 (배율 고정 1:1) |
| `SPEC.md` | **전체 사양서 — 계산식·검증 기준의 유일한 기준** |

```bash
python3 build.py                 # 전체 빌드 → 여성복원형Suite-포터블.html
cd 기본원형
node engine-verify.js            # 제도 검증 (DXF 정답지 대조 + 봉제 정합성 + 매끄러움)
node calibrate.js                # 곡선 상수 재적합 (engine.js 의 CAL 블록을 직접 갱신)
node print-verify.js             # 인쇄 1:1 검증
node dxf-verify.js               # DXF 왕복·원본 대조 검증
node qa-verify.js                # 독립 검증기 (기준이 낡아 일부 FAIL — SPEC 개정 전 기준)

cd ../숙녀복기본원형1
node engine-verify.js            # 66호 DXF 대조 + 봉제 정합성 + 전 호수
node engine-verify.js --calibrate  # 곡선 상수 재적합 (engine.js 의 CAL 블록을 직접 갱신)
```

## 검증 기준
`기본원형/dxf-66-groundtruth.json` — 원본 AutoCAD 도면(66호)에서 추출한 좌표 정답지.
엔진 출력이 이 좌표와 **0.05cm 이내**로 일치해야 합니다.

> ⚠ DXF 폴리라인은 스플라인이라 정점에 **곡선 위의 점(fit, `70&8`)** 과 **곡선 밖의 제어점(`70&16`)** 이 섞여 있습니다.
> 반드시 `curves[].local`(fit 정점만, 로컬 좌표 변환 완료)을 쓰세요. 제어점을 섞으면 0.4cm 가짜 오차가 납니다.

## 알려진 사항
- **앞 옆선은 계산식 `B/4+1.5 = 23.4`** 를 씁니다. 원본 DXF 는 23.5(반올림)이라 앞판 곡선이 최대 0.1cm 차이납니다 — 호수별 그레이딩을 깨끗하게 유지하기 위한 의도적 선택입니다.
- **큰 호수일수록 옆선이 짧아집니다** (44호 17.0 → 88호 13.0). 진동깊이 `B/4+0.6` 은 호수당 +1.5 로 커지는데 등길이는 +0.5 라서 생기는 교재 계산식의 필연적 결과입니다. 14.0cm 미만이면 앱이 경고합니다.
- **숙녀복 기본원형1 의 뒤 허리선은 도면과 다릅니다.** 원본 DXF 는 앞뒤를 한 사각형(앞길이 40)에 그려 뒤 허리선도 40 에 있는데, 그대로 두면 앞뒤 옆선이 2.5cm 어긋나 봉제가 안 됩니다. 엔진은 등길이(37.5)를 써서 앞뒤 옆선을 맞춥니다 — SPEC §19-2.
- **숙녀복 기본원형1 의 앞암홀 허용편차는 0.10cm** 입니다. 원본 DXF 스플라인이 자기가 표시한 앞품선 2등분점을 0.10 벗어나 지나가서, 그보다 좁히면 도면의 오차를 따라 그리게 됩니다 — SPEC §19-3.
- **소매는 기본원형에서 제외했습니다.** 제공된 반소매 도면이 "숙녀복기본원형1 반소매 47P" 로 다른 원형의 소매이기 때문입니다(AH 42.82 vs 47.19). 엔진에 코드는 남아 있고 `opt.includeSleeve = true` 로 되살아납니다 — 자세한 내용은 SPEC §17.
- **곡선은 전부 C2 연속 스플라인**입니다 (SPEC §22·§23). 목선·암홀은 어깨선에 **수직으로 도착**하도록 고정했습니다 — 앞뒤가 어깨솔기에서 매끄럽게 이어지려면 필요한 규칙이고, 원본 도면(3~13° 벗어남)보다 이 규칙을 우선했습니다.
- **실제 프린터 1:1 출력은 미검증입니다.** PDF 는 MediaBox(A4 = 595.276×841.890pt)와 검교정 사각형(50.0000mm)까지 파일 내용으로 확인했지만, 실제로 종이에 뽑아 자로 잰 것은 아닙니다.
- **실제 CAD 로 DXF 를 열어보지 못했습니다.** 자체 파서 2종으로 구조·좌표만 검증했습니다.
