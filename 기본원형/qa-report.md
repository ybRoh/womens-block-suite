## 2. ★ 겨드랑 오차의 원인 규명 — 결론: **측정 방식의 착시**

### 2.1 원인

총괄이 보고한 「뒤암홀 y=22.40 에서 Δ 0.140 FAIL」은 **곡선이 틀린 게 아니라 재는 방법이 틀린 것**입니다.

### 8-2. ★ 치명적 모순 — 사양이 자기 합격기준을 못 지킵니다

§3.4 구성(대각선 + 수선 발점 + 법선 오프셋 뒤 +1.50/−1.23 · 앞 +1.48/−1.49)대로 소매산 곡선을 실제로 그려 길이를 쟀습니다.

| 호수 | capReduce | 뒤곡선 / 뒤AH | 앞곡선 / 앞AH | **이세분** | 요구 | 판정 |
|---|---|---|---|---|---|---|
| 55호 | **0.50 (기본)** | 22.278 / 21.933 | 21.958 / 21.485 | **0.818** | 1.5~3.0 | **FAIL** |
| 66호 | **0.50 (기본)** | 24.082 / 23.801 | 23.780 / 23.385 | **0.676** | 1.5~3.0 | **FAIL** |
| 77호 | **0.50 (기본)** | 25.907 / 25.682 | 25.626 / 25.298 | **0.553** | 1.5~3.0 | **FAIL** |
| 55호 | 0.00 | 22.763 / 21.933 | 22.439 / 21.485 | 1.785 | | OK |
| 66호 | 0.00 | 24.569 / 23.801 | 24.265 / 23.385 | 1.648 | | OK |
| 77호 | 0.00 | 26.396 / 25.682 | 26.113 / 25.298 | 1.529 | | OK |

**원인은 산수입니다.** 대각선 합 = `AH − 2·capReduce`. 오프셋 ±1.5 가 만드는 활(bow) 여유는 양쪽 합쳐 **약 1.65 cm** 뿐입니다. 따라서

> 이세분 ≈ 1.65 − 2 × capReduce

- `capReduce = 0.5` (기본값) → **0.65** ✗
- `capReduce = 0` → **1.65** — 겨우 하한 통과
- 이세분 **3.0 을 만들려면 capReduce = −0.68** 이 필요 → §3.4 가 정한 범위 `0~1` 밖

즉 **§3.4 의 `capReduce` 허용범위 0~1 전체에서 이세분 상한 3.0 은 도달 불가**이고, **기본값 0.5 는 하한 1.5 도 못 넘습니다.** 그대로 구현하면 개발팀은 반드시 자기 검증에서 FAIL 합니다.

또한 §3.4 의 "뒤 소매산 곡선 길이 ≥ 뒤AH" 는 `capReduce=0.5` 에서 곡선이 대각선보다 최소 0.500 cm(뒤)·0.500 cm(앞) 길어져야 겨우 성립하는 아슬아슬한 조건입니다(실측 여유 0.281/0.395 — 통과하긴 하나 여유 없음).

**총괄 결정 요청**: 다음 중 하나가 필요합니다.
1. `capReduce` 기본값을 **0** 으로, 허용범위를 **−1.0 ~ 0.5** 로 (이세분 1.5~3.0 을 실제로 만들 수 있음)
2. 오프셋 ±1.5 를 **AH 비례 스케일**로 바꿔 활 여유를 키움
3. 합격기준 「이세분 1.5~3.0」을 「0.5~2.0」 등 현실값으로 낮춤

### 8-3. 마크 위치가 DXF 와 재현되지 않음 (알려진 사항의 정량화)

§3.4 ⚠ 절이 인정한 대로, DXF 마크는 AH 가 아니라 **소매폭**의 /8, /12+0.6 입니다. 제가 직접 재확인했습니다.

```
DXF 마크 5.354 → /8 역산 AH = 42.832
DXF 마크 4.169 → (x−0.6)·12 역산 AH = 42.828     ← 두 마크는 서로 일치
DXF 소매폭 42.819 → /8 = 5.352 · /12+0.6 = 4.168  ← 마크와 일치 (소매폭 기준이 맞음)
DXF 소매산 14.874 → (x−2)·4 역산 AH = 51.496     ← 전혀 다른 값
```

교재 제도법(AH 기준)을 채택하면 수선 발점 위치 t 가 이동합니다.

| | DXF 실측 t | AH 기준 t (66호) |
|---|---|---|
| 뒤 상단 / 하단 | 0.171 / 0.867 | **0.204 / 0.843** |
| 앞 상단 / 하단 | 0.166 / 0.834 | **0.206 / 0.794** |

오프셋 값 ±1.5 는 DXF 의 t 위치에서 측정된 것이므로, 다른 t 에 그대로 적용하면 소매산 형상이 원본과 달라집니다(위 8-2 의 길이 부족에 일부 기여). **§3.4 의 "형상 기준으로만 쓴다"는 결정은 유효하나, 오프셋 값 자체를 t 위치와 함께 재적합해야 합니다.**

### 8-4. 원본 소매 DXF 는 이 몸판의 소매가 아닙니다

- 66호 5개 곡선의 DXF 대조 (양방향 최단거리, 0.25cm 조밀 샘플링)
- 앞목 원호 구간 별도 검증 (지금까지 아무도 안 했음)
- 교재 지정 통과점 13개, 겨드랑 구성선 역산 4개
- 앞·뒤 옆선 길이 일치, 어깨선 이세, 암홀·목둘레 단조 증가 (55·66·77호)
- 폐곡선 · 자기교차 0 · 폴리라인 간격 · 골선 시접 0 · 끝점 접선
- 인쇄 레이아웃 27조합 무예외, 1:1 배율 인자 = 1
- 세 팀 파일 통합 실행(DOM) — 스크립트 에러 0, 렌더 정상

**검증 못 함 (데이터/환경 부족)**
- **실제 브라우저 인쇄 결과** — 브라우저 도구가 다른 세션에 점유되어 접근 실패. 통합 실행은 jsdom 으로 대체했고, 인쇄 결함(§7-2 a·b)은 **CSS 캐스케이드와 DOM 중첩의 정적 분석**으로 판정했습니다. `!important` 가 걸린 `display:none` 이 `!important` 없는 `display:block` 을 이기는 것은 CSS 명세상 확정적이지만, **실제 종이 출력은 확인하지 않았습니다.**
- **1:1 실물 치수** — 프린터로 뽑아 자로 재야 합니다. 스크립트로는 `scaleFactor=1`, `declaredMm=50` 까지만 확인.
- **착용감 / 진동 깊이의 적정성** — 77호 옆선 14.0cm 가 실제로 불편한지는 가봉 필요. §9-5 가 경고를 띄우기로 한 이유입니다.
- **소매산 이세 배분의 봉제 가능성** — §8-2 의 이세분 수치는 계산값이며, 실제 오그림 가능 여부는 소재에 달렸습니다.
