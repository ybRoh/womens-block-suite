### 1. 앞 옆선이 뒤 옆선보다 **유차만큼 길다** (2.512 / 77·88호 2.812)

원문 구조 그대로다. 41 이 13 에서 유차 올라간 점([20])이라 앞 옆선은 반드시 유차만큼 길다.
그 값을 **앞 다트로 뺏어야** 꿰맬 수 있는데, 원문 [27] 은

> 「다트를 넣는 위치와 방법은 여러가지가 있으며 꼭 집어서 어느부분에 넣어야 한다는
> 공식이나 원칙은 없습니다」

라며 두 자리를 예로만 든다.

- **65** = 41 에서 5cm 내려간 곳 → BP 를 향한 선  (**옆 다트**)
- **66** = 59 에서 **유차** 내려간 곳 → BP 를 향한 선  (**밑단 다트**)

원문이 정하지 않았으므로 **엔진이 임의로 고르지 않았다.** 대신 `draftVest` 가 경고를
내보내고 검산기 §4 가 「차 = 유차인가」를 잰다 (유차 ±0.1 을 벗어나면 실패 —
유차가 아닌 다른 이유로 어긋나면 바로 걸린다).

→ **사용자에게 어느 쪽을 쓸지 물어본 뒤** 그 다트를 넣어라. 넣고 나면 검산기 §4 의
   soft 를 hard 로 바꿔라 (옆선 차 0.1 이내).

**2026-08-14 추가 실측 — 도면은 「둘 중 하나」가 아니라 둘 다 쓴다.**
`11_앞판이미지`(13~41 = 유차 2.5 를 자로 삼아 재면) 41 → 윗다리 **4.29**(원문 「5정도」),

   넣을 때 다트분은 **옆선 차(2.4932 / 2.7922)** 를 쓰는 편이 낫다 — 정답지의 2.757 은

넣을 때 주의:
- 글자 그대로의 66(= 59 에서 유차 아래)은 **밑단보다 2.5cm 아래 허공**이다. 66 을
  「옆선 위에서 65 로부터 **호길이** 유차만큼 내려간 점」으로 잡아라.
- 꼭짓점은 **58 에서 1.5~2 짧게**. 58 은 절개선 변 위의 점이라 거기까지 파면 앞옆 조각이
  그 점에서 집힌다(시접 오프셋이 깨진다).
- 두 다리 길이가 최대 0.14 차가 난다 — 접어서 옆선을 다시 그리는 트루잉을 하거나
  꼭짓점을 두 다리의 수직이등분선 위로 옮겨라.
- 65 는 지금 [14] 의 `hemUp`(30번용)을 빌려 쓴다. `K.sideDartAt` 로 분리해라 —
  슬라이더 하나가 30·62·65 셋을 같이 흔든다.
- 넣으면 `measures.sideFrontSewn` 을 **다트 뺀 값**으로 채우고, `dart-verify §7` 의
  「봉제 후 옆선 짝」이 참고에서 **실패**로 자동 승격된다. `engine-verify §3` 의 66 줄도
  「옆선 위의 점인가 · 65 에서 호길이 = 유차인가」로 바꿔라.

### 2. 어깨 짝이 0.23 남는다 (뒤 − 앞 · 전 호수 0.227~0.237)

0.64 → 0.23 으로 줄였다(수정 1번). 어깨 11cm 의 2% 라 **이세로 먹일 수 있는 크기**이고
검산기는 경고로 둔다(0.30 초과면 실패).

남은 0.23 의 원인은 **26·52 의 해석**이다. 지금은 원문을 글자 그대로 읽어
「26 = 21에서 1.5 내려온 곳」·「52 = 20에서 1.5 내려온 곳」으로 잡았다(둘 다 기초선 기준).
다른 해석은 **어깨선을 S~N 안내선(뒤 22~24 · 앞 48~51) 위에 올리는 것**이다.

**★ 2026-08-14 4차 — 정답지는 S~N 안내선 쪽이다.** 앞 어깨선 위 8점을 최소제곱으로
맞추면 기울기 0.373, x=19(어깨/2) 에서 **y = 3.02**. S~N(48~51) 을 x=19 까지 늘린 값이
**3.17**(0.15 차)이고, 엔진의 「20에서 1.5」는 **1.5**(1.52 차)다. 옆목점도 같다 —
어깨선 × 앞목선 교점 실측 **(8.78, −0.79)**, S~N 위의 같은 x 는 **−0.81**(0.02 차),
엔진 53 은 (8.5, −1.5). 즉 정답지에서 **52·53 이 둘 다 S~N 선 위**에 있다.
3차의 「도면 실측 52 의 y ≈ 1.8」은 `11_앞판이미지`(모식 확대 · ±1cm)에서 나온 값이라
이쪽이 훨씬 단단하다.
→ 그래도 **원문 글자를 앞세우는 규칙**대로 (19, 1.5) 를 그대로 뒀다. 바꾸면 어깨 짝이
   0.23 → 0.12 로 줄고 앞 AH 가 커진다. 재단물이 바뀌므로 사용자 확인 항목이다.

### 3. ~~도면 대조가 눈대중이다~~ → **4차에서 픽셀 대조로 바꿨다**

`9_뒤판이미지2` / `11_앞판이미지` 는 90° 눕혀 있고 어깨 부근이 **모식도로 확대**돼 있어

### 5. 안단 — **선은 넣었다**(4차). 남은 것은 **조각으로 떠내기**

`K.facing*` 7개로 네 줄(앞 안단선 · 뒤 안단선 · 앞뒤 밑단 안단)을 조각마다 잘라 붙였다.
아직 **표시선(internal)** 이라 재단물이 아니다. 안단 조각을 뜨려면
앞: 안단선 + 앞목선 + 여밈선 + 밑단안단선 / 뒤: 안단선 + 뒷목선 + 뒤중심 으로 닫힌
조각을 새로 만들고(`mk` 에 edges 로), 시접·식서·`cutCount` 를 주면 된다.
겉감 조각의 안단선은 그대로 두는 편이 좋다(붙이는 자리 표시).

### 6. 앞목선이 정답지에서는 **직선이 아니라 곡선**이다

엔진은 53→72 **직선**(V 넥)이다 — 원문에 앞목선 정의가 없어 `11_앞판이미지` 에서 읽은
해석이다(doc §5). 정답지를 재면 같은 두 끝점을 쓰되 **현에서 최대 1.77cm 안쪽으로 부푼
곡선**이다 (y=10 부근이 가장 크다 · 실측 x 4.98 ↔ 현 3.44).

```
 y     0.4  2.8  5.2  7.7 10.1 12.5 14.9 17.3
 도면 x 8.48 7.80 7.09 6.15 4.98 3.14 1.91 −0.15
 현  x 8.23 7.07 5.92 4.71 3.44 2.04 0.76 −0.69
```
부푸는 쪽이 **조각 안쪽**이므로 곡선이면 목이 그만큼 **더 파인다**. 재단물이 바뀌므로
넣지 않았다. 넣을 때 `fNeck` 만 곡선으로 바꾸면 되고(변 개수·조각 위상은 그대로),
앞 MP 다리가 이 선 위에 있으므로(아래 7번) 같이 옮겨야 한다.

### 7. MP 두 개가 정답지와 자리·모양이 다르다

- **뒤 MP** — 엔진은 `mpAt 0.55` 로 암홀 위 y=15.0 에 잡고 **0.65 짜리 토막 점선**만 낸다.
  정답지는 다리가 암홀의 **훨씬 아래**(y ≈ 20.6·21.2 · 진동선 바로 위, 비율로 ≈0.83)에
  0.8~0.85 벌어져 있고, 두 다리가 **허리의 33 까지 내려가 만난다**(꼭짓점이 절개선 위).
  즉 도면은 「접어서 절개선 솔기로 먹인다」를 그림으로 보여 준다.
- **앞 MP** — 엔진은 53~68 선 위(9.19, 13.1)에서 68 쪽으로 0.75. 정답지는 다리가
  **앞목선 위**(y ≈ 11.8·12.6 · 벌어짐 ≈ 0.98)에 있고 꼭짓점이 **68**이다.
  원문 [39] 「목이 파인 옷은 앞이 뜨는 것을 막으려고」와 맞는 그림이다(목선에서 접는다).

둘 다 원문이 「적당한 곳」이라고만 해 자리를 안 정한 자리다. 꼭짓점을 그리면 접는 방향이
드러나므로, 바꾼다면 **다리 2개 + 꼭짓점**의 쐐기로 내는 편이 도면에 가깝다.
