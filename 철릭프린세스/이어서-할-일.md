# 철릭 프린세스 — 진행 기록

## 1차 (2026-08-14) — 기본형 몸판을 프린세스로 갈랐다

**바탕**: `철릭기본형` 모듈 전체를 복제한 뒤 **몸판만** 고쳤다.
소매·깃·치마·고름·동정은 손대지 않았다 (사용자 요청 「앞뒤판만」).

### 절개선 작도 — 2차에서 사용자 스케치대로 다시 잡았다 (2026-08-14)

```
출발  어깨선에서 princessAt 0.52 자리
뒤    → 견갑골(진동선 높이 · **뒤중심 쪽으로** 1.00) → 허리 0.40
앞    → **BP** → 허리 (BP 에서 앞중심 쪽으로 0.60 더)
끝접선 위아래 모두 세로   CAL.princess k0/k1 0.20
```

1차에는 토르소 값 그대로 **옆선 쪽으로** 휘게 했는데, 사용자가 스케치로
「이런 모양이었으면 좋겠다 · 앞판은 BP점을 지나야 이쁘지」라고 짚어 주었다.
두 선 모두 **중심 쪽으로** 휘는 것이 맞다 — 뒤는 견갑골, 앞은 BP 가 안쪽에 있다.

### ★ BP — 철릭 치수에는 유장·유폭이 없다

철릭 치수는 `B · W · 등길이 · 치마길이 · 어깨너비 · 소매길이 · 깃길이` 뿐이다.
숙녀복 원형(B 84 에서 유폭 16 · 유장 25 · 등길이 38)에서 비율로 세웠다:

```
유폭/2 = B × 0.0952      (84 × 0.0952 = 8.00)     K.bustHalfAt
유장   = 등길이 × 0.658   (38 × 0.658 = 25.0)      K.bustLenAt
```

⚠ **앞판 좌표는 x=0 이 「여밈 끝」이고 몸 중심은 x = 여밈분** 이다.
옆선 36.38 = 여밈 13.73 + B/4 22.65 로 맞아떨어지는 것이 근거다.
그래서 `BP.x = 여밈분 + 유폭/2` 다. 66호반에서 **BP (22.36, 25.96)**.
여기를 몸 중심(x=0)으로 잘못 읽으면 BP 가 여밈분만큼 안쪽으로 밀린다.

앞 절개선 너치도 **BP 에 찍는다** — 봉제할 때 맞출 자리다.

### ★ 철릭에는 다트가 없다 — 절개선은 **순수 분할선**이다

서양 프린세스는 다트를 절개선에 옮겨 담는다. 철릭 몸판은 겨드랑~허리가
거의 수직이라(뒤 23.64 → 22.39) 옮길 다트가 없다. 그래서:

- 절개선 짝 길이 차 = **0** (같은 곡선을 공유한다 · 회전이 없다)
- 두 조각을 도로 붙이면 기본형 몸판 **그대로**

검산기 §1-B 가 매 호수에서 기본형 엔진을 불러와 그것을 확인한다 —
어깨 합 · 허리 합 · 절개선 짝 · 절개선이 조각 안에 있는지.

### 검산기에서 바꾼 것

| | 기본형 | 프린세스 |
|---|---|---|
| 조각 수 | 9장 | **11장** |
| 도면 크기 대조 | 6조각 | 소매·깃·치마 4조각만 (몸판은 절개해서 못 견준다) |
| 도면 외곽선 겹치기 | 6조각 | 같은 4조각만 |
| 몸판 검사 | — | **§1-B 기본형 대조**로 대신한다 |

`suite-verify.js` 의 절개선 짝 허용치는 **0.06** 이다 — 샘플 간격 하나다.
실제 곡선은 양방향 38.4904 로 똑같은데 `edgesToLoop` 가 이음매에서 점을
하나 덜어내는 방향이 달라 963 vs 962 점이 된다. 기하 오차가 아니다.
