# 철릭 프린세스 — 진행 기록

## 1차 (2026-08-14) — 기본형 몸판을 프린세스로 갈랐다

**바탕**: `철릭기본형` 모듈 전체를 복제한 뒤 **몸판만** 고쳤다.
소매·깃·치마·고름·동정은 손대지 않았다 (사용자 요청 「앞뒤판만」).

### 절개선 작도 — 토르소원형프린세스라인 벤치마킹

```
출발  어깨선을 2등분한 자리        princessAt 0.5   (토르소 도면 ✳ 표시)
경유  진동선 높이 · 옆선 쪽으로 부풀림  bPrinBow 0.35 · fPrinBow 0.45
끝    허리 — 폭의 비율               bPrinWaistAt 0.50 · fPrinWaistAt 0.62
끝접선 위아래 모두 **세로**          CAL.princess k0/k1 0.20
```

앞이 0.62 인 이유: 앞판은 **여밈분(13.73)이 붙어 있어** 폭의 절반이 몸의
절반이 아니다. 옆선 쪽으로 더 나가야 해부학적으로 BP 아래에 온다.

### ★ 철릭에는 다트가 없다 — 절개선은 **순수 분할선**이다

서양 프린세스는 다트를 절개선에 옮겨 담는다. 철릭 몸판은 겨드랑~허리가
거의 수직이라(뒤 23.64 → 22.39) 옮길 다트가 없다. 그래서:

- 절개선 짝 길이 차 = **0** (같은 곡선을 공유한다 · 회전이 없다)
- 두 조각을 도로 붙이면 기본형 몸판 **그대로**

검산기 §1-B 가 매 호수에서 기본형 엔진을 불러와 그것을 확인한다 —
어깨 합 · 허리 합 · 절개선 짝 · 절개선이 조각 안에 있는지.

### 검산기에서 바꾼 것

| | 기본형 | 프린세스 |
|---|---|---|
| 조각 수 | 9장 | **11장** |
| 도면 크기 대조 | 6조각 | 소매·깃·치마 4조각만 (몸판은 절개해서 못 견준다) |
| 도면 외곽선 겹치기 | 6조각 | 같은 4조각만 |
| 몸판 검사 | — | **§1-B 기본형 대조**로 대신한다 |

`suite-verify.js` 의 절개선 짝 허용치는 **0.06** 이다 — 샘플 간격 하나다.
실제 곡선은 양방향 38.4904 로 똑같은데 `edgesToLoop` 가 이음매에서 점을
하나 덜어내는 방향이 달라 963 vs 962 점이 된다. 기하 오차가 아니다.
