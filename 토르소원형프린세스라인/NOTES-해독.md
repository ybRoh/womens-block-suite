## 아직 DXF 로 풀어야 할 것



1. **뒤 가슴선이 `H/4 + 1.9` 가 맞는가** — 뒤판 쪽 수평선 실측이 **26.265** 와 **25.265** 두 개다.
   H/4+1.9 = 26.16 (26.265 와 0.10 차) · H/4+1 = 25.26 (25.265 와 **정확히 일치**) ·
   B/4+1.9 = 23.8 (안 맞음). **B/4 는 아니다**가 확실해졌고, 두 수평선이 각각 어느 레벨인지만
   가리면 된다. 상단선은 y 1579.751 (58.5 수직선의 위끝)
2. **`MP` 와 옆선 다트 `1.5`** — BP 에서 옆선으로 빗금 웨지가 있는데 **남기는 다트인지 접어
   없애는 표시인지** 판독 불가. 분리된 앞옆면 조각에도 내부선으로 남아 있다
3. 옆목점 `1(⅜)` · 뒷목점 `0.3(⅛)` 의 방향(넓힘/올림/내림)
4. 허리 다트 `c` / `○` 의 배분식 (기호만 있고 등식이 없다)
5. **앞 어깨 기울기** — 도면에 수치 표기 자체가 없다
