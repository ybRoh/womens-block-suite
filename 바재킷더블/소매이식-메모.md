# 2장소매 이식 메모 (원형2 → 바재킷더블)

## 왜 아직 안 붙였나

`숙녀복기본원형2` 의 2장소매는 **호출 인터페이스는 깨끗한데 의존이 크다.**

```js
twoSleeveGeom(m, opt, AHb, AHf)   // 뒤/앞 암홀 길이만 주면 된다 ← 좋다
twoSleevePieces(s, seam)          // → [큰소매, 작은소매]
```

그런데 이 두 함수(+`capGeom`) **372줄** 외에 아래가 다 필요하다.
붙이다 만 소매를 남기느니 목록을 남기고 끊었다.

## 딸려 오는 것 — 이걸 다 옮겨야 한다

## 붙이는 순서

1. 위 K·CAL·헬퍼를 재킷 엔진으로 복사 (이름 충돌 확인 — `ptOnSegsAtY` 는 이미 있다)
2. `draftJacket` 에서 **우리 암홀 길이**로 호출:
   ```js
   var AHb = sLen(g.backArm), AHf = sLen(g.frontArm);
   var sv = twoSleeveGeom(m, opt, AHb, AHf);
   pieces.push.apply(pieces, twoSleevePieces(sv, seam));
   ```
3. `suite-verify.js` 의 바재킷 `pairs` 에 **2장소매 절개선 짝** 추가
   (원형2 것과 같은 형태 — 큰소매 「뒤 절개선」 ↔ 작은소매 「절개선」, 허용 0.15)
4. `engine-verify.js` §1 의 조각 수 검사 7 → **9** 로

## ★ 이미 잡혀 있는 것 (다시 하지 말 것)
